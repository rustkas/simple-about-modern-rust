# Приложение C. Ownership Quick Reference

Все основные правила владения (ownership), заимствования (borrowing) и времён жизни (lifetimes) в краткой и систематизированной форме.

---

## C.1. Основные правила владения

| Правило | Описание |
| --- | --- |
| **1** | Каждое значение в Rust имеет переменную-владельца (owner) |
| **2** | В любой момент времени у значения может быть только один владелец |
| **3** | Когда владелец выходит из области видимости, значение уничтожается (вызывается `drop`) |

```rust
{
    let s = String::from("hello");  // s — владелец
}   // s выходит из области видимости — память освобождена

```

---

## C.2. Перемещение (Move)

**Происходит при:** присваивании, передаче в функцию, возврате из функции — для non-Copy типов.

```rust
let s1 = String::from("hello");
let s2 = s1;        // s1 перемещается в s2
// println!("{}", s1); // ❌ Ошибка! s1 больше не владеет значением

```

**Визуально:**

```
До:  s1 ───▶ "hello"
После: s2 ───▶ "hello"   (s1 недействителен)

```

---

## C.3. Копирование (Copy)

**Происходит при:** присваивании, передаче в функцию — для Copy-типов.

**Copy-типы:**

* Все целые числа: `i8`, `u8`, `i16`, `u16`, `i32`, `u32`, `i64`, `u64`, `isize`, `usize`
* Логический: `bool`
* Символы: `char`
* Кортежи из Copy-типов: `(i32, i32)`

```rust
let x = 5;
let y = x;          // x копируется в y
println!("{} {}", x, y); // ✅ обе переменные доступны

```

**Визуально:**

```
До:  x = 5
После: x = 5, y = 5

```

---

## C.4. Клонирование (Clone)

**Происходит при:** явном вызове `.clone()` — для любых типов.

```rust
let s1 = String::from("hello");
let s2 = s1.clone();  // создаётся полная копия
println!("{} {}", s1, s2); // ✅ обе переменные доступны

```

**Визуально:**

```
До:  s1 ───▶ "hello"
После: s1 ───▶ "hello"
       s2 ───▶ "hello"  (новая копия в памяти)

```

---

## C.5. Сравнение Move / Copy / Clone

| Операция | Типы | Что происходит | Исходная переменная |
| --- | --- | --- | --- |
| **Move** | non-Copy (`String`, `Vec<T>`) | Копируется указатель, данные в куче остаются на месте | Становится недействительной |
| **Copy** | Copy (`i32`, `bool`) | Копируются данные (бит-в-бит) | Остаётся действительной |
| **Clone** | Любые (с `Clone`) | Глубокая копия всех данных | Остаётся действительной |

## C.6. Заимствование (Borrowing)

**Неизменяемое заимствование — `&T`:**

```rust
fn borrow(s: &String) {
    println!("{}", s); // только чтение
}

let s = String::from("hello");
borrow(&s);
println!("{}", s); // ✅ s всё ещё доступен

```

**Изменяемое заимствование — `&mut T`:**

```rust
fn borrow_mut(s: &mut String) {
    s.push_str(" world"); // изменение
}

let mut s = String::from("hello");
borrow_mut(&mut s);
println!("{}", s); // "hello world"

```

---

## C.7. Правила заимствования

| Правило | Описание |
| --- | --- |
| **1** | Либо несколько неизменяемых ссылок (`&T`), либо одна изменяемая (`&mut T`) |
| **2** | Нельзя иметь изменяемую и неизменяемые ссылки одновременно |
| **3** | Ссылки всегда должны быть действительными (не висячими) |

**Примеры:**

```rust
let mut s = String::from("rust");

// ✅ Много неизменяемых
let r1 = &s;
let r2 = &s;
println!("{} and {}", r1, r2);

// ✅ Изменяемая — одна (после использования неизменяемых)
let r3 = &mut s;
r3.push_str(" 2024");
println!("{}", r3);

```

## C.8. Времена жизни (Lifetimes)

**Явные аннотации — `'a`:**

```rust
fn longest<'a>(a: &'a str, b: &'a str) -> &'a str {
    if a.len() > b.len() { a } else { b }
}

```

**Правила элизии (когда аннотации не нужны):**

| Правило | Описание |
| --- | --- |
| **1** | Каждый параметр-ссылка получает своё время жизни |
| **2** | Если один параметр-ссылка, возвращаемая ссылка получает его время жизни |
| **3** | Если несколько параметров, но один — `&self` или `&mut self`, возвращаемая ссылка получает его время жизни |

**Примеры:**

```rust
// Элизия работает автоматически
fn first_word(s: &str) -> &str {
    let bytes = s.as_bytes();
    for (i, &item) in bytes.iter().enumerate() {
        if item == b' ' {
            return &s[0..i];
        }
    }
    s
}

fn main() {
    let text = String::from("hello world");
    let word = first_word(&text);
    println!("Первое слово: {}", word);
}

```

## C.9. `'static` — статическое время жизни

```rust
let s: &'static str = "hello"; // живёт всё время работы программы

```

**Когда использовать:** строковые литералы, константы, данные, существующие всё время работы программы.

**Не использовать:** для данных, создаваемых во время выполнения.

## C.10. Область видимости

```rust
fn main() {
    let s = String::from("hello"); // s создаётся

    {
        let t = String::from("world"); // t создаётся
        println!("{} {}", s, t);
    } // t уничтожается

    println!("{}", s);
} // s уничтожается

```

**Правило:** переменная живёт от объявления до конца области видимости (блока `{}`).

## C.11. Функции и владение

| Ситуация | Что происходит |
| --- | --- |
| Передача значения (`fn foo(s: String)`) | Владение перемещается в функцию |
| Передача ссылки (`fn foo(s: &String)`) | Заимствование — владение остаётся у вызывающего |
| Передача изменяемой ссылки (`fn foo(s: &mut String)`) | Изменяемое заимствование |
| Возврат значения (`fn foo() -> String`) | Владение возвращается вызывающему |

```rust
fn take_ownership(s: String) {
    println!("{}", s);
} // s уничтожается

fn return_ownership() -> String {
    let s = String::from("hello");
    s // владение возвращается
}

fn main() {
    let my_string = return_ownership();
    take_ownership(my_string);
}

```

## C.12. Структуры и владение

```rust
struct User {
    name: String,   // владеет
    age: u32,       // копируется
}

// Ссылки в структурах — нужен lifetime
struct Cache<'a> {
    data: &'a [u8], // заимствует
}

fn main() {
    let raw_data = vec![1, 2, 3, 4];
    let cache = Cache { data: &raw_data };
    println!("Дэш-кэш длина: {}", cache.data.len());
}

```

## C.13. Владение в коллекциях

```rust
// Vec владеет своими элементами
let mut v = Vec::new();
v.push(String::from("hello")); // строка перемещается в вектор

// После перемещения
let s = String::from("hello");
v.push(s);
// println!("{}", s); // ❌ s перемещён

```

## C.14. Чек-лист: проверка владения

| Вопрос | Ответ |
| --- | --- |
| Кто владеет этим значением? | Один владелец |
| Может ли быть несколько владельцев? | Нет (кроме `Rc`/`Arc`) |
| Что происходит при присваивании? | Move (non-Copy) или Copy (Copy-типы) |
| Нужна ли копия? | Используйте `.clone()` |
| Хочу только читать | Используйте `&T` |
| Хочу изменять | Используйте `&mut T` |
| Хочу передать владение | Используйте `fn foo(T)` |
| Хочу вернуть владение | Используйте возвращаемое значение |
