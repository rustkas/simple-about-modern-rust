# Приложение O. Rust 2018 → 2026 Migration Map

Это приложение — **главная карта миграции** для программиста, переходящего с Rust 2018 на Rust 2026. Оно систематизирует изменения за это время и показывает, что нужно знать сегодня.

---

## O.1. Общая карта изменений

| Область                     | Rust 2018      | Rust 2026            | Важность  |
| --------------------------- | -------------- | -------------------- | --------- |
| **Edition**                 | 2018           | 2024                 | Критичная |
| **Async traits**            | Внешний макрос | Встроенная поддержка | Критичная |
| **Async closures**          | Не было        | Стабилизируются      | Высокая   |
| **`let-else`**              | Не было        | Есть                 | Средняя   |
| **`let` chains**            | Не было        | Есть                 | Средняя   |
| **GAT**                     | Не было        | Есть                 | Высокая   |
| **RPITIT**                  | Не было        | Есть                 | Высокая   |
| **Const generics**          | Ограниченно    | Основные случаи OK   | Высокая   |
| **`LazyLock` / `OnceLock`** | Внешние крейты | В `std`              | Средняя   |
| **`cargo add`**             | Не было        | Есть                 | Высокая   |
| **Rust-analyzer**           | RLS            | LSP-стандарт         | Критичная |
| **Clippy**                  | ~100+ линтов   | 500+ линтов          | Средняя   |
| **Tokio**                   | Растущий       | Доминирует           | Критичная |
| **Axum**                    | Не было        | Популярный веб-стек  | Высокая   |
| **SQLx**                    | Растущий       | Широко используется  | Высокая   |
| **`thiserror` / `anyhow`**  | Уже были       | Де-факто стандарт    | Средняя   |

### Главное из этого приложения

После этого приложения мы:

- **Понимаем** изменения между Rust 2018 и Rust 2026.
- **Знаем**, что изменилось в языке, типах, async, инструментах и экосистеме.
- **Умеем** спланировать миграцию проектов.
- **Видим** обязательный минимум для современного Rust-разработчика.

**Самая важная идея:**

> Rust 2018 → Rust 2026 — эволюция, а не революция. Язык стал удобнее, инструменты — мощнее, экосистема — зрелее. Главное: Edition 2024, встроенные async traits, `let-else`/`let` chains, GAT, rust-analyzer, `cargo add`, современный веб/БД-стек. Знания 2018 года по-прежнему ценны — их нужно дополнить, а не заменить.
