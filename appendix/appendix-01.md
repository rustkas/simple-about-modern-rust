# Приложение A. Rust 2018 → Rust 2024

Это приложение представляет собой **систематическую таблицу изменений** между Rust 2018 и Rust 2024. Оно предназначено для быстрой ориентации: что появилось, что изменилось и как это влияет на код.

## A.10. Что изменилось: детали

### Ключевые добавления

1. **GAT** — ассоциированные типы с параметрами.
2. **Async traits** — асинхронные методы в трейтах.
3. **RPITIT** — `impl Trait` в методах трейтов.
4. **`let-else`** — декларативный синтаксис для проверки Option.
5. **`let` chains** — объединение условий с `let`.
6. **`LazyLock`** — ленивая инициализация в `std`.
7. **`OnceLock`** — однократная инициализация в `std`.

### Пример использования ключевых возможностей Rust 2024

```rust
use std::sync::LazyLock;

// LazyLock для ленивой инициализации глобальных констант/структур
static GLOBAL_CONFIG: LazyLock<String> = LazyLock::new(|| {
    String::from("Production Environment")
});

// Встроенный асинхронный трейт (без сторонних макросов вроде #[async_trait])
pub trait DataSource {
    async fn fetch_data(&self) -> Result<String, &'static str>;
}

struct NetworkSource;

impl DataSource for NetworkSource {
    async fn fetch_data(&self) -> Result<String, &'static str> {
        Ok(String::from("Данные успешно загружены"))
    }
}

#[tokio::main]
async fn main() {
    let opt_value: Option<i32> = Some(42);

    // 1. let-else синтаксис для раннего выхода
    let Some(number) = opt_value else {
        return;
    };

    // 2. let chains в условных конструкциях
    if number > 10 && let Some(parsed) = Some(number * 2) {
        println!("Число прошло проверку: {}", parsed);
    }

    println!("Конфигурация: {}", *GLOBAL_CONFIG);

    let source = NetworkSource;
    if let Ok(data) = source.fetch_data().await {
        println!("{}", data);
    }
}

```

### Ключевые изменения

1. **`cargo add`** — вместо ручного редактирования `Cargo.toml`.
2. **Rust-analyzer** — вместо RLS.
3. **Feature resolver v2** — улучшенное разрешение фич.
4. **MSRV** — поле `rust-version` в `Cargo.toml`.

## A.11. Практические рекомендации

### Для проектов на Rust 2018

1. **Обновите Edition** до 2024:
```bash
cargo fix --edition

```


2. **Обновите зависимости**:
```bash
cargo upgrade

```


3. **Перейдите на rust-analyzer**:
* Установите расширение для вашего редактора.


4. **Используйте новые возможности**:
* `let-else` для удобной проверки.
* Async traits для асинхронных интерфейсов.
* `LazyLock` для ленивой инициализации.

### Главное из этого приложения

После этого приложения мы понимаем:

* **Ключевые изменения** между Rust 2018 и Rust 2024.
* **Что появилось** — GAT, async traits, let-else, LazyLock, OnceLock.
* **Что изменилось** — Cargo, инструменты, rust-analyzer.
* **Как мигрировать** — пошаговый процесс обновления.

**Самая важная идея:**

> Rust 2018 → Rust 2024 — это не революция, а эволюция. Большинство изменений — это добавления, а не поломки. Новые возможности делают язык более выразительным и удобным, не нарушая совместимости. Переход на Rust 2024 — это инвестиция в будущее проекта, которая окупается улучшенной производительностью, безопасностью и удобством разработки.
