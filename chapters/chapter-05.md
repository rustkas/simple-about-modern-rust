# Глава 5. Управление выполнением программы

До этого момента наши программы выполнялись последовательно: одна инструкция за другой, сверху вниз.

Но настоящая программа почти никогда не работает только по такому сценарию. Она должна принимать решения, повторять действия, прекращать повторение, пропускать отдельные шаги и выбирать один из нескольких вариантов поведения.

Для этого Rust предоставляет несколько конструкций управления выполнением:

* `if` и `else`;
* `while`;
* `loop`;
* `for`;
* `break`;
* `continue`;
* метки циклов;
* диапазоны;
* условные конструкции `if let`;
* `match`;
* `let`-chains в Edition 2024.

При этом важно помнить уже знакомый нам принцип Rust:

> Многие конструкции Rust являются **выражениями** и поэтому могут возвращать значение.

Это особенно заметно на примере `if` и `match`.

Все примеры этой главы используют **Rust Edition 2024** и подготовлены для запуска непосредственно в [Rust Playground](https://play.rust-lang.org/).

## 5.1. Выражение `if`

Конструкция `if` позволяет выполнить блок кода только тогда, когда условие имеет значение `true`.

Простейший пример:

```rust
fn main() {
    if 2 + 2 == 4 {
        println!("Математика работает");
    }
}
```

[▶ Открыть пример в Rust Playground](https://play.rust-lang.org/?version=stable&mode=debug&edition=2024&code=fn%20main%28%29%20%7B%0A%20%20%20%20if%202%20%2B%202%20%3D%3D%204%20%7B%0A%20%20%20%20%20%20%20%20println%21%28%22%D0%9C%D0%B0%D1%82%D0%B5%D0%BC%D0%B0%D1%82%D0%B8%D0%BA%D0%B0%20%D1%80%D0%B0%D0%B1%D0%BE%D1%82%D0%B0%D0%B5%D1%82%22%29%3B%0A%20%20%20%20%7D%0A%7D)

Условие `2 + 2 == 4` вычисляется в `bool`. Если результат — `true`, выполняется блок внутри фигурных скобок. Если `false` — блок пропускается.

Пример с ложным условием:

```rust
fn main() {
    if 2 + 2 == 5 {
        println!("Эта строка не будет напечатана");
    }

    println!("Программа продолжается");
}
```

### Условие `if` должно быть логическим

Rust **не** преобразует произвольные значения в `bool`. Следующий код неверен:

```rust
fn main() {
    let number = 1;

    if number {
        println!("Число");
    }
}
```

`number` имеет тип `i32`, а `if` требует значение типа `bool`. Это один из характерных примеров философии Rust:

> Компилятор не пытается угадать, что имел в виду программист.

## 5.2. Синтаксис `if`

В Rust условие `if` не заключается в обязательные круглые скобки:

```rust
if number > 10 {
    println!("Большое число");
}
```

а не:

```rust
if (number > 10) {
    println!("Большое число");
}
```

Круглые скобки при этом могут использоваться внутри самого выражения, если они действительно нужны для изменения порядка вычислений:

```rust
if (number > 10) && (number < 100) {
    println!("Число находится между 10 и 100");
}
```

Фигурные скобки, обозначающие блок, являются обязательными.

Попробуйте самостоятельно убрать их и посмотреть на сообщение компилятора.

## 5.3. `if` и `else`

Если необходимо выполнить один блок при истинном условии, а другой — при ложном, используется `else`.

```rust
fn main() {
    let number = 7;

    if number > 10 {
        println!("Число больше 10");
    } else {
        println!("Число не больше 10");
    }
}
```

Теперь программа всегда выполняет один из двух блоков.

## 5.4. `else if`

Если вариантов больше двух, можно последовательно проверять несколько условий:

```rust
fn main() {
    let number = -5;

    if number > 100 {
        println!("Большое положительное число");
    } else if number > 0 {
        println!("Положительное число");
    } else if number < 0 {
        println!("Отрицательное число");
    } else {
        println!("Ноль");
    }
}
```

Условия проверяются сверху вниз. Как только находится первое `true`, выполняется соответствующий блок, а остальные условия уже не проверяются.

## 5.5. `if` как выражение

Здесь начинается важная особенность Rust.

`if` — не только конструкция управления выполнением. Это **выражение**, которое может вернуть значение.

Поэтому мы можем написать:

```rust
fn main() {
    let number = 10;

    let message = if number > 0 {
        "положительное"
    } else {
        "отрицательное или ноль"
    };

    println!("{message}");
}
```

[▶ Открыть пример в Rust Playground](https://play.rust-lang.org/?version=stable&mode=debug&edition=2024&code=fn%20main%28%29%20%7B%0A%20%20%20%20let%20number%20%3D%2010%3B%0A%0A%20%20%20%20let%20message%20%3D%20if%20number%20%3E%200%20%7B%0A%20%20%20%20%20%20%20%20%22%D0%BF%D0%BE%D0%BB%D0%BE%D0%B6%D0%B8%D1%82%D0%B5%D0%BB%D1%8C%D0%BD%D0%BE%D0%B5%22%0A%20%20%20%20%7D%20else%20%7B%0A%20%20%20%20%20%20%20%20%22%D0%BE%D1%82%D1%80%D0%B8%D1%86%D0%B0%D1%82%D0%B5%D0%BB%D1%8C%D0%BD%D0%BE%D0%B5%20%D0%B8%D0%BB%D0%B8%20%D0%BD%D0%BE%D0%BB%D1%8C%22%0A%20%20%20%20%7D%3B%0A%0A%20%20%20%20println%21%28%22%7Bmessage%7D%22%29%3B%0A%7D)

Результат:

```text
положительное
```

Сначала вычисляется `if`, а затем его результат присваивается переменной `message`.

### Ветви должны возвращать совместимый тип

Следующий пример **неверен**:

```rust
fn main() {
    let value = if true {
        10
    } else {
        "ten"
    };

    println!("{value}");
}
```

# 5.7. Цикл `while`

`while` позволяет повторять блок кода до тех пор, пока условие остаётся истинным.

```rust
fn main() {
    let mut number = 1;

    while number <= 5 {
        println!("{number}");
        number += 1;
    }
}
```

[▶ Открыть пример в Rust Playground](https://play.rust-lang.org/?version=stable&mode=debug&edition=2024&code=fn%20main%28%29%20%7B%0A%20%20%20%20let%20mut%20number%20%3D%201%3B%0A%0A%20%20%20%20while%20number%20%3C%3D%205%20%7B%0A%20%20%20%20%20%20%20%20println%21%28%22%7Bnumber%7D%22%29%3B%0A%20%20%20%20%20%20%20%20number%20%2B%3D%201%3B%0A%20%20%20%20%7D%0A%7D)

Порядок действий здесь следующий:

1. проверить условие;
2. если оно `true`, выполнить тело цикла;
3. вернуться к условию;
4. повторить процесс;
5. когда условие станет `false`, выйти из цикла.

## 5.8. Изменение переменной внутри цикла

Обратите внимание на `mut`:

```rust
let mut number = 1;
```

Мы изменяем значение переменной:

```rust
number += 1;
```

Поэтому переменная должна быть изменяемой.

Без `mut` программа не скомпилируется.

# 5.9. `break`

Иногда необходимо прекратить цикл раньше, чем его условие станет `false`.

Для этого используется `break`.

```rust
fn main() {
    let mut number = 1;

    while number <= 10 {
        println!("{number}");

        if number == 5 {
            break;
        }

        number += 1;
    }

    println!("Цикл завершён");
}
```

Когда `number` становится равным `5`, выполняется:

```rust
break;
```

и выполнение сразу выходит из цикла.

# 5.10. `continue`

`continue` не завершает цикл. Он прекращает текущую итерацию и переходит к следующей.

```rust
fn main() {
    let mut number = 0;

    while number < 10 {
        number += 1;

        if number % 2 == 0 {
            continue;
        }

        println!("{number}");
    }
}
```

# 5.11. Бесконечный цикл `loop`

Rust предоставляет специальную конструкцию для бесконечного цикла:

```rust
loop {
    // код
}
```

Например:

```rust
fn main() {
    let mut number = 1;

    loop {
        println!("{number}");

        number += 1;

        if number > 5 {
            break;
        }
    }
}
```

[▶ Открыть пример в Rust Playground](https://play.rust-lang.org/?version=stable&mode=debug&edition=2024&code=fn%20main%28%29%20%7B%0A%20%20%20%20let%20mut%20number%20%3D%201%3B%0A%0A%20%20%20%20loop%20%7B%0A%20%20%20%20%20%20%20%20println%21%28%22%7Bnumber%7D%22%29%3B%0A%0A%20%20%20%20%20%20%20%20number%20%2B%3D%201%3B%0A%0A%20%20%20%20%20%20%20%20if%20number%20%3E%205%20%7B%0A%20%20%20%20%20%20%20%20%20%20%20%20break%3B%0A%20%20%20%20%20%20%20%20%7D%0A%20%20%20%20%7D%0A%7D)

`loop` не имеет условия завершения. Он будет повторяться, пока выполнение не встретит `break`, `return` или другой механизм выхода из функции.

## 5.12. `loop` как выражение

Как и `if`, `loop` является выражением.

У `break` может быть значение:

```rust
fn main() {
    let result = loop {
        break 42;
    };

    println!("{result}");
}
```

[▶ Открыть пример в Rust Playground](https://play.rust-lang.org/?version=stable&mode=debug&edition=2024&code=fn%20main%28%29%20%7B%0A%20%20%20%20let%20result%20%3D%20loop%20%7B%0A%20%20%20%20%20%20%20%20break%2042%3B%0A%20%20%20%20%7D%3B%0A%0A%20%20%20%20println%21%28%22%7Bresult%7D%22%29%3B%0A%7D)

Результат:

```text
42
```

`break 42;` завершает цикл и возвращает значение `42`. Поэтому переменная `result` получает результат работы цикла.

Более реалистичный пример:

```rust
fn main() {
    let mut counter = 0;

    let result = loop {
        counter += 1;

        if counter == 10 {
            break counter * 2;
        }
    };

    println!("Результат: {result}");
}
```

# 5.13. Цикл `for`

Цикл `for` предназначен для последовательного перебора элементов некоторого значения, которое реализует механизм итерации.

Самый простой пример:

```rust
fn main() {
    for number in 1..6 {
        println!("{number}");
    }
}
```

## 5.15. Диапазоны и `for`

Конструкция `1..6` создаёт диапазон от `1` до `6`, **не включая `6`**:

```text
1 2 3 4 5
```

Это называется полуинтервалом `[start, end)`.

Включающий диапазон:

```rust
1..=5
```

Теперь `5` тоже входит:

```rust
fn main() {
    for number in 1..=5 {
        println!("{number}");
    }
}
```

[▶ Открыть пример в Rust Playground](https://play.rust-lang.org/?version=stable&mode=debug&edition=2024&code=fn%20main%28%29%20%7B%0A%20%20%20%20for%20number%20in%201..%3D5%20%7B%0A%20%20%20%20%20%20%20%20println%21%28%22%7Bnumber%7D%22%29%3B%0A%20%20%20%20%7D%0A%7D)

Современный Rust поддерживает несколько форм диапазонов:

```rust
1..5      // от 1 до 4
1..=5     // от 1 до 5
1..       // от 1 и дальше (потенциально бесконечный)
..5       // до 5 (без начала)
..=5      // до 5 включительно (без начала)
..        // полный диапазон
```

Не все формы одинаково применимы к `for`.

Диапазоны с начальной точкой (`1..5`, `1..=5`, `1..`) могут использоваться как итераторы.

Потенциально бесконечный диапазон:

```rust
fn main() {
    for number in 1.. {
        println!("{number}");

        if number == 5 {
            break;
        }
    }
}
```

[▶ Открыть пример в Rust Playground](https://play.rust-lang.org/?version=stable&mode=debug&edition=2024&code=fn%20main%28%29%20%7B%0A%20%20%20%20for%20number%20in%201..%20%7B%0A%20%20%20%20%20%20%20%20println%21%28%22%7Bnumber%7D%22%29%3B%0A%0A%20%20%20%20%20%20%20%20if%20number%20%3D%3D%205%20%7B%0A%20%20%20%20%20%20%20%20%20%20%20%20break%3B%0A%20%20%20%20%20%20%20%20%7D%0A%20%20%20%20%7D%0A%7D)

Диапазоны без начальной точки (`..5`, `..=5`, `..`) сами по себе не являются последовательностями, которые можно перебрать с помощью `for`. Например:

```rust

        println!("{number}");
```

Однако эти формы полезны при работе со срезами:


# 5.18. Метки циклов

При вложенных циклах обычный `break` относится к ближайшему окружающему циклу.

Иногда необходимо выйти сразу из внешнего цикла.

Для этого используются метки.

```rust
fn main() {
    'outer: for x in 1..=3 {
        for y in 1..=3 {
            if x == 2 && y == 2 {
                break 'outer;
            }

            println!("x = {x}, y = {y}");
        }
    }
}
```

[▶ Открыть пример в Rust Playground](https://play.rust-lang.org/?version=stable&mode=debug&edition=2024&code=fn%20main%28%29%20%7B%0A%20%20%20%20%27outer%3A%20for%20x%20in%201..%3D3%20%7B%0A%20%20%20%20%20%20%20%20for%20y%20in%201..%3D3%20%7B%0A%20%20%20%20%20%20%20%20%20%20%20%20if%20x%20%3D%3D%202%20%26%26%20y%20%3D%3D%202%20%7B%0A%20%20%20%20%20%20%20%20%20%20%20%20%20%20%20%20break%20%27outer%3B%0A%20%20%20%20%20%20%20%20%20%20%20%20%7D%0A%0A%20%20%20%20%20%20%20%20%20%20%20%20println%21%28%22x%20%3D%20%7Bx%7D%2C%20y%20%3D%20%7By%7D%22%29%3B%0A%20%20%20%20%20%20%20%20%7D%0A%20%20%20%20%7D%0A%7D)

Метка:

```rust

```

указывает, к какому циклу относится `break`.

Метки можно использовать и с `continue`.

```rust
fn main() {
    'outer: for x in 1..=3 {
        for y in 1..=3 {

        }
    }
}
```

Метки особенно полезны во вложенных циклах, когда обычного `break` или `continue` недостаточно.

# 5.19. `if let`

До сих пор `if` проверял логическое выражение:

```rust
if number > 10 {
    // ...
}
```

Но в Rust существует другой способ условной проверки — `if let`.

Он особенно полезен, когда мы хотим проверить, соответствует ли значение определённому шаблону.

Пока мы не будем подробно разбирать перечисления, но можем использовать `Option`:

```rust
fn main() {
    let value = Some(42);

    if let Some(number) = value {
        println!("Получили число: {number}");
    }
}
```

[▶ Открыть пример в Rust Playground](https://play.rust-lang.org/?version=stable&mode=debug&edition=2024&code=fn%20main%28%29%20%7B%0A%20%20%20%20let%20value%20%3D%20Some%2842%29%3B%0A%0A%20%20%20%20if%20let%20Some%28number%29%20%3D%20value%20%7B%0A%20%20%20%20%20%20%20%20println%21%28%22%D0%9F%D0%BE%D0%BB%D1%83%D1%87%D0%B8%D0%BB%D0%B8%20%D1%87%D0%B8%D1%81%D0%BB%D0%BE%3A%20%7Bnumber%7D%22%29%3B%0A%20%20%20%20%7D%0A%7D)

Здесь:

```rust
Some(number)
```

является шаблоном.

Если значение действительно содержит `Some`, внутреннее значение извлекается в переменную `number`.

`if let` мы подробно разберём после знакомства с `enum`, `Option`, `Result` и pattern matching.

## 5.21. `let` chains

Edition 2024 добавила возможность объединять несколько условий с `let` в одной цепочке:

```rust
fn main() {
    let value = Some(42);

    if let Some(number) = value && number > 40 {
        println!("Число больше 40: {number}");
    }
}
```

[▶ Открыть пример в Rust Playground](https://play.rust-lang.org/?version=stable&mode=debug&edition=2024&code=fn%20main%28%29%20%7B%0A%20%20%20%20let%20value%20%3D%20Some%2842%29%3B%0A%0A%20%20%20%20if%20let%20Some%28number%29%20%3D%20value%20%26%26%20number%20%3E%2040%20%7B%0A%20%20%20%20%20%20%20%20println%21%28%22%D0%A7%D0%B8%D1%81%D0%BB%D0%BE%20%D0%B1%D0%BE%D0%BB%D1%8C%D1%88%D0%B5%2040%3A%20%7Bnumber%7D%22%29%3B%0A%20%20%20%20%7D%0A%7D)

## 5.22. `match`

Когда вариантов становится много, длинная цепочка `if` и `else if` может стать неудобной.

Rust предоставляет для таких случаев конструкцию `match`.

Простейший пример:

```rust
fn main() {
    let number = 2;

    match number {
        1 => println!("Один"),
        2 => println!("Два"),
        3 => println!("Три"),
        _ => println!("Другое число"),
    }
}
```

Символ `_` означает «любой другой вариант».

`match` также является выражением:

```rust
fn main() {
    let number = 2;

    let text = match number {
        1 => "one",
        2 => "two",
        3 => "three",
        _ => "other",
    };

    println!("{text}");
}
```

В отличие от многих языков программирования, Rust требует, чтобы `match` был **исчерпывающим**: все возможные варианты должны быть обработаны.

Это станет особенно важным при изучении `enum`.

## 5.23. Управление выполнением и выражения

Теперь мы можем увидеть общую картину.

Следующие конструкции могут непосредственно участвовать в построении выражений:

```rust
if
match
loop
```

Например:

```rust
fn main() {
    let number = 7;

    let result = if number % 2 == 0 {
        "even"
    } else {
        "odd"
    };

    println!("{result}");
}
```

[▶ Открыть пример в Rust Playground](https://play.rust-lang.org/?version=stable&mode=debug&edition=2024&code=fn%20main%28%29%20%7B%0A%20%20%20%20let%20number%20%3D%207%3B%0A%0A%20%20%20%20let%20result%20%3D%20if%20number%20%25%202%20%3D%3D%200%20%7B%0A%20%20%20%20%20%20%20%20%22even%22%0A%20%20%20%20%7D%20else%20%7B%0A%20%20%20%20%20%20%20%20%22odd%22%0A%20%20%20%20%7D%3B%0A%0A%20%20%20%20println%21%28%22%7Bresult%7D%22%29%3B%0A%7D)

Это отличается от привычной модели, в которой условная конструкция воспринимается исключительно как инструкция.

В Rust выражения образуют основу языка.

Позже эта особенность станет особенно важной при работе с функциями, `match`, `Option`, `Result`, блоками и замыканиями.

## 5.24. Что изменилось по сравнению с Rust 2018*

Если вы знакомы с Rust 2018, основная логика управления выполнением программы покажется вам знакомой:

* `if`;
* `else`;
* `while`;
* `loop`;
* `for`;
* `break`;
* `continue`;
* диапазоны;
* метки циклов.

Эти фундаментальные конструкции не были заменены новой моделью.

Однако современный Rust предлагает более развитые средства композиции:

* `if` активно используется как выражение;
* `loop` может возвращать значение через `break`;
* `if let` позволяет выполнять условный pattern matching;
* `let` chains позволяют объединять проверки;
* `match` является полноценным выражением и требует исчерпывающего разбора вариантов;
* Edition 2024 предоставляет современный синтаксис, который мы используем в этой книге.

Поэтому переход от Rust 2018 к современному Rust — это не изучение полностью нового языка.

Скорее, это переход от знания отдельных конструкций к пониманию того, **как эти конструкции составляют единую систему выражений, типов, областей видимости и pattern matching**.

---

## Практика

Теперь попробуйте самостоятельно изменить программы этой главы.

### Задание 1

Создайте программу, которая принимает число, записанное непосредственно в коде, и сообщает:

* число отрицательное;
* число равно нулю;
* число положительное.

---

### Задание 2

Создайте цикл `for`, который выводит числа от `1` до `100`, но:

* пропускает чётные числа;
* прекращается после `75`.

Используйте `continue` и `break`.

---

### Задание 3

Создайте вложенные циклы:

```text
1 × 1
1 × 2
...
```

и остановите внешний цикл при достижении определённого значения с помощью метки.

---

### Задание 4

Используйте `if` как выражение:

```rust
let result = if ... {
    ...
} else {
    ...
};
```

Получите таким способом строку `"even"` или `"odd"` в зависимости от значения числа.

---

### Задание 5

Создайте бесконечный `loop`, который увеличивает число и завершает работу через `break`, когда число достигает `100`.

Попробуйте сделать так, чтобы `loop` **вернул значение** через `break`.

---

### Задание 6

Эксперимент с компилятором.

Измените следующий код:

```rust
let value = if true {
    10
} else {
    "ten"
};
```

Попробуйте сделать так, чтобы программа скомпилировалась.

Объясните самому себе, **почему первоначальный вариант не работает**.

---

### Задание 7

Попробуйте изменить Edition в Playground для примера с `let` chains.

Сравните поведение:

```text
Edition 2024
```

и более старой Edition.

Посмотрите не только на результат, но и на сообщение компилятора.

---

## Главное из этой главы

После этой главы мы умеем:

* проверять условия с помощью `if`;
* использовать `else` и `else if`;
* получать значения из `if`;
* повторять код с помощью `while`;
* создавать бесконечные циклы через `loop`;
* возвращать значение из `loop` через `break`;
* перебирать последовательности с помощью `for`;
* использовать диапазоны;
* управлять циклом с помощью `break` и `continue`;
* работать с вложенными циклами;
* использовать метки циклов;
* понимать назначение `if let`;
* видеть `match` как выражение;
* понимать, зачем Rust требует исчерпывающий `match`;
* познакомиться с `let` chains в Edition 2024.

Самое важное — начать воспринимать управление выполнением не как набор отдельных команд, а как часть единой модели Rust:

```text
выражение
    ↓
вычисление значения
    ↓
тип результата
    ↓
следующее выражение
```

Именно эта модель будет становиться всё более важной в следующих главах.
