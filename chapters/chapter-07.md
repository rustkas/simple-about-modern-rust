# Глава 7. Составные типы

До этого момента мы работали с простыми типами: числами, логическими значениями, символами. Но реальные данные почти никогда не бывают такими простыми. Координаты точки — это два числа. Данные пользователя — это имя, возраст и статус. Результат операции — это успех или ошибка.

Rust предоставляет несколько способов группировать значения в более сложные структуры. В этой главе мы познакомимся с двумя фундаментальными составными типами: **кортежами (tuples)** и **массивами (arrays)**.

Все примеры этой главы используют **Rust Edition 2024** и подготовлены для запуска непосредственно в [Rust Playground](https://play.rust-lang.org/).

---

## 7.1. Кортежи: группы разнородных значений

Кортеж — это составное значение фиксированной длины, которое может содержать элементы **разных типов**.

```rust
fn main() {
    let point = (10, 20);
    let user = ("Alice", 30, true);
    let empty = ();

    println!("point: {:?}", point);
    println!("user: {:?}", user);
    println!("empty: {:?}", empty);
}
```

[▶ Открыть пример в Rust Playground](https://play.rust-lang.org/?version=stable&mode=debug&edition=2024&code=fn%20main%28%29%20%7B%0A%20%20%20%20let%20point%20%3D%20%2810%2C%2020%29%3B%0A%20%20%20%20let%20user%20%3D%20%28%22Alice%22%2C%2030%2C%20true%29%3B%0A%20%20%20%20let%20empty%20%3D%20%28%29%3B%0A%0A%20%20%20%20println%21%28%22point%3A%20%7B%3A%3F%7D%22%2C%20point%29%3B%0A%20%20%20%20println%21%28%22user%3A%20%7B%3A%3F%7D%22%2C%20user%29%3B%0A%20%20%20%20println%21%28%22empty%3A%20%7B%3A%3F%7D%22%2C%20empty%29%3B%0A%7D)

Тип кортежа определяется его структурой: `(i32, i32)`, `(&str, i32, bool)`. Пустой кортеж `()` имеет специальное название — **unit type**. Он обозначает отсутствие значимого значения.

Важно понимать: кортеж — это **одно значение**, которое содержит несколько других значений.

## 7.2. Доступ к элементам кортежа

В отличие от многих языков, в Rust доступ к элементам кортежа осуществляется не по имени, а по позиции, начиная с нуля:

```rust
fn main() {
    let point = (10, 20);

    let x = point.0;
    let y = point.1;

    println!("x = {}, y = {}", x, y);
}
```

[▶ Открыть пример в Rust Playground](https://play.rust-lang.org/?version=stable&mode=debug&edition=2024&code=fn%20main%28%29%20%7B%0A%20%20%20%20let%20point%20%3D%20%2810%2C%2020%29%3B%0A%0A%20%20%20%20let%20x%20%3D%20point.0%3B%0A%20%20%20%20let%20y%20%3D%20point.1%3B%0A%0A%20%20%20%20println%21%28%22x%20%3D%20%7B%7D%2C%20y%20%3D%20%7B%7D%22%2C%20x%2C%20y%29%3B%0A%7D)

Обратите внимание: синтаксис `point.0` похож на доступ к полю структуры, но здесь `0`, `1`, `2` — это не имена, а индексы.

## 7.3. Деструктуризация кортежей

Более идиоматичный способ получить элементы кортежа — **деструктуризация** (разборка) с помощью `let`:

```rust
fn main() {
    let point = (10, 20);

    let (x, y) = point;

    println!("x = {}, y = {}", x, y);
}
```

Деструктуризация работает и с большими кортежами:

## 7.4. Игнорирование элементов при деструктуризации

Если какие-то элементы кортежа не нужны, их можно пропустить с помощью `_`:

## 7.7. Массивы: группы однотипных значений

Массив — это составное значение фиксированной длины, которое содержит элементы **одного типа**.

**Создание массива:**

```rust
fn main() {
    let numbers = [1, 2, 3, 4, 5];
    let chars = ['a', 'b', 'c'];
    let flags = [true, false, true];

    println!("numbers: {:?}", numbers);
    println!("chars: {:?}", chars);
    println!("flags: {:?}", flags);
}
```

[▶ Открыть пример в Rust Playground](https://play.rust-lang.org/?version=stable&mode=debug&edition=2024&code=fn%20main%28%29%20%7B%0A%20%20%20%20let%20numbers%20%3D%20%5B1%2C%202%2C%203%2C%204%2C%205%5D%3B%0A%20%20%20%20let%20chars%20%3D%20%5B%27a%27%2C%20%27b%27%2C%20%27c%27%5D%3B%0A%20%20%20%20let%20flags%20%3D%20%5Btrue%2C%20false%2C%20true%5D%3B%0A%0A%20%20%20%20println%21%28%22numbers%3A%20%7B%3A%3F%7D%22%2C%20numbers%29%3B%0A%20%20%20%20println%21%28%22chars%3A%20%7B%3A%3F%7D%22%2C%20chars%29%3B%0A%20%20%20%20println%21%28%22flags%3A%20%7B%3A%3F%7D%22%2C%20flags%29%3B%0A%7D)

Тип массива записывается как `[T; N]`, где `T` — тип элементов, а `N` — длина (количество элементов). Например: `[i32; 5]` — массив из пяти целых чисел.

## 7.8. Инициализация массива

В Rust есть два способа создания массива:

1. **Перечислением значений:**

```rust
let numbers = [1, 2, 3, 4, 5];
```

2. **Повторением одного значения заданное количество раз:**

```rust
fn main() {
    let zeros = [0; 10];      // массив из 10 нулей
    let ones = [1; 5];        // массив из 5 единиц
    let points = [(0, 0); 3]; // массив из 3 кортежей (0, 0)

    println!("zeros: {:?}", zeros);
    println!("ones: {:?}", ones);
    println!("points: {:?}", points);
}
```

## 7.11. 🔨 Сломайте код: Выход за границы массива

Что произойдёт, если попытаться получить доступ к элементу по индексу, выходящему за пределы массива?

```rust
fn main() {
    let numbers = [10, 20, 30];
    let value = numbers[10];
    println!("{}", value);
}
```

[▶ Открыть пример с ошибкой в Rust Playground](https://play.rust-lang.org/?version=stable&mode=debug&edition=2024&code=fn%20main%28%29%20%7B%0A%20%20%20%20let%20numbers%20%3D%20%5B10%2C%2020%2C%2030%5D%3B%0A%20%20%20%20let%20value%20%3D%20numbers%5B10%5D%3B%0A%20%20%20%20println%21%28%22%7B%7D%22%2C%20value%29%3B%0A%7D)

Запустите этот пример. Программа **не компилируется**.

Массив `[10, 20, 30]` и индекс `10` известны компилятору уже во время компиляции. Rust заранее вычисляет, что обращение гарантированно выйдет за границы, и превращает это в ошибку компиляции. Мы уже видели похожий механизм в главе 2 с `10 / 0`.

Если индекс становится известен только во время выполнения:

```rust
fn main() {
    let numbers = [10, 20, 30];
    let index = std::env::args().count() + 10;

    let value = numbers[index];
    println!("{}", value);
}
```

[▶ Открыть пример в Rust Playground](https://play.rust-lang.org/?version=stable&mode=debug&edition=2024&code=fn%20main%28%29%20%7B%0A%20%20%20%20let%20numbers%20%3D%20%5B10%2C%2020%2C%2030%5D%3B%0A%20%20%20%20let%20index%20%3D%20std%3A%3Aenv%3A%3Aargs%28%29.count%28%29%20%2B%2010%3B%0A%0A%20%20%20%20let%20value%20%3D%20numbers%5Bindex%5D%3B%0A%20%20%20%20println%21%28%22%7B%7D%22%2C%20value%29%3B%0A%7D)

Эта программа успешно компилируется, но при запуске аварийно завершается с **паникой** (`index out of bounds`). Rust проверяет границы массива во время выполнения и не позволяет обратиться к несуществующей памяти — это важная гарантия безопасности.

## 7.14. Unit type: `()`

В Rust есть специальный тип, который не содержит никакой информации — **unit type**, обозначаемый `()`.

Мы уже сталкивались с ним:

- Функции, которые не возвращают значение, фактически возвращают `()`.
- Блоки кода, которые не заканчиваются выражением, возвращают `()`.

Вспомним правило: блок кода в Rust — это выражение, и его значением становится значение **последнего выражения** в блоке. Если последняя строка — оператор (заканчивается на `;`), блок возвращает `()`.

```rust
fn main() {
    // Последняя строка — оператор → блок возвращает ()
    let result_unit = {
        let x = 5;
        let _ = x + 1;
    };

    // Последняя строка — выражение → блок возвращает его значение
    let result_value = {
        let x = 5;
        x + 1
    };

    println!("result_unit: {:?}", result_unit); // ()
    println!("result_value: {}", result_value); // 6
}
```

[▶ Открыть пример в Rust Playground](https://play.rust-lang.org/?version=stable&mode=debug&edition=2024&code=fn%20main%28%29%20%7B%0A%20%20%20%20let%20result_unit%20%3D%20%7B%0A%20%20%20%20%20%20%20%20let%20x%20%3D%205%3B%0A%20%20%20%20%20%20%20%20let%20_%20%3D%20x%20%2B%201%3B%0A%20%20%20%20%7D%3B%0A%0A%20%20%20%20let%20result_value%20%3D%20%7B%0A%20%20%20%20%20%20%20%20let%20x%20%3D%205%3B%0A%20%20%20%20%20%20%20%20x%20%2B%201%0A%20%20%20%20%7D%3B%0A%0A%20%20%20%20println%21%28%22result_unit%3A%20%7B%3A%3F%7D%22%2C%20result_unit%29%3B%0A%20%20%20%20println%21%28%22result_value%3A%20%7B%7D%22%2C%20result_value%29%3B%0A%7D)

Разница между двумя блоками — ровно в одной точке с запятой.

Unit type важен в нескольких местах:

1. **Функции без возврата** фактически имеют сигнатуру `-> ()`.
2. **Игнорирование значений** через `let _ = ...` явно показывает, что результат сознательно не используется.
3. В обобщённом коде `()` часто обозначает «здесь намеренно нет значения».

Понимание `()` пригодится дальше — этот тип регулярно встречается в сигнатурах функций и при работе с выражениями.

## 7.15. Кортежи и массивы: в чём разница?

Теперь, когда мы знаем оба типа, важно чётко понимать их отличия:

| Характеристика      | Кортеж (Tuple)          | Массив (Array)            |
| ------------------- | ----------------------- | ------------------------- |
| **Типы элементов**  | Могут быть разными      | Должны быть одинаковыми   |
| **Размер**          | Фиксированный           | Фиксированный             |
| **Доступ**          | По индексу (`.0`, `.1`) | По индексу (`[0]`, `[1]`) |
| **Синтаксис**       | `(10, "hello")`         | `[1, 2, 3]`               |
| **Тип в аннотации** | `(i32, &str)`           | `[i32; 3]`                |

```rust
fn main() {
    // Кортеж: разные типы
    let mixed = (42, "hello", true);

    // Массив: один тип
    let numbers = [1, 2, 3, 4, 5];

    println!("mixed: {:?}, numbers: {:?}", mixed, numbers);
}
```
