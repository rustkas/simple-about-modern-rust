# Глава 4. Логические значения и сравнения

В предыдущих главах мы научились работать со значениями, переменными и bindings. Теперь пришло время научиться **задавать вопросы программе**.

Программа должна уметь не только вычислять числа:

```rust
let result = 2 + 2;
```

но и отвечать на вопросы:

```text
2 больше 1?
пользователь вошёл в систему?
значение равно нулю?
два условия выполняются одновременно?
хотя бы одно условие выполнено?
```

Для этого Rust предоставляет логический тип `bool`, операции сравнения и логические операторы.

---

## 4.1. Логический тип `bool`

В Rust логический тип называется `bool`.

У него всего два возможных значения:

```rust
true
false
```

Пример:

```rust
fn main() {
    let is_rust_fun = true;
    let is_rust_easy = false;

    println!("{is_rust_fun}");
    println!("{is_rust_easy}");
}
```

[▶ Открыть пример в Rust Playground](https://play.rust-lang.org/?version=stable&mode=debug&edition=2024&code=fn%20main%28%29%20%7B%0A%20%20%20%20let%20is_rust_fun%20%3D%20true%3B%0A%20%20%20%20let%20is_rust_easy%20%3D%20false%3B%0A%0A%20%20%20%20println%21%28%22%7Bis_rust_fun%7D%22%29%3B%0A%20%20%20%20println%21%28%22%7Bis_rust_easy%7D%22%29%3B%0A%7D)

Результат:

```text
true
false
```

Можно явно указать тип:

```rust
fn main() {
    let ready: bool = true;
    let finished: bool = false;

    println!("{ready}");
    println!("{finished}");
}
```

[▶ Открыть пример в Rust Playground](https://play.rust-lang.org/?version=stable&mode=debug&edition=2024&code=fn%20main%28%29%20%7B%0A%20%20%20%20let%20ready%3A%20bool%20%3D%20true%3B%0A%20%20%20%20let%20finished%3A%20bool%20%3D%20false%3B%0A%0A%20%20%20%20println%21%28%22%7Bready%7D%22%29%3B%0A%20%20%20%20println%21%28%22%7Bfinished%7D%22%29%3B%0A%7D)

Логическое значение часто является **результатом какого-либо выражения**:

```rust
fn main() {
    let result = 2 < 5;

    println!("{result}");
}
```

[▶ Открыть пример в Rust Playground](https://play.rust-lang.org/?version=stable&mode=debug&edition=2024&code=fn%20main%28%29%20%7B%0A%20%20%20%20let%20result%20%3D%202%20%3C%205%3B%0A%0A%20%20%20%20println%21%28%22%7Bresult%7D%22%29%3B%0A%7D)

Результат:

```text
true
```

Это важная идея:

> **Сравнение в Rust — это выражение, результатом которого является значение типа `bool`.**

## 4.2. Операторы сравнения

Rust предоставляет шесть основных операторов сравнения:

| Оператор | Значение           |
|----------|--------------------|
| `==`     | равно              |
| `!=`     | не равно           |
| `<`      | меньше             |
| `<=`     | меньше или равно   |
| `>`      | больше             |
| `>=`     | больше или равно   |

Пример:

```rust
fn main() {
    println!("{}", 2 == 2);
    println!("{}", 2 != 3);
    println!("{}", 1 < 2);
    println!("{}", 2 <= 2);
    println!("{}", 3 > 2);
    println!("{}", 3 >= 3);
}
```

[▶ Открыть пример в Rust Playground](https://play.rust-lang.org/?version=stable&mode=debug&edition=2024&code=fn%20main%28%29%20%7B%0A%20%20%20%20println%21%28%22%7B%7D%22%2C%202%20%3D%3D%202%29%3B%0A%20%20%20%20println%21%28%22%7B%7D%22%2C%202%20%21%3D%203%29%3B%0A%20%20%20%20println%21%28%22%7B%7D%22%2C%201%20%3C%202%29%3B%0A%20%20%20%20println%21%28%22%7B%7D%22%2C%202%20%3C%3D%202%29%3B%0A%20%20%20%20println%21%28%22%7B%7D%22%2C%203%20%3E%202%29%3B%0A%20%20%20%20println%21%28%22%7B%7D%22%2C%203%20%3E%3D%203%29%3B%0A%7D)

Результат:

```text
true
true
true
true
true
true
```

Важно не путать `==` и `=`:

```rust
number == 10   // сравнение: «равно ли number десяти?»
number = 10;   // присваивание: «записать в number значение 10»
```

В Rust это две совершенно разные операции.

# 4.4. Сравнение логических значений

Логические значения тоже можно сравнивать на равенство:

```rust
fn main() {
    println!("{}", true == true);
    println!("{}", true == false);
    println!("{}", true != false);
}
```

[▶ Открыть пример в Rust Playground](https://play.rust-lang.org/?version=stable&mode=debug&edition=2024&code=fn%20main%28%29%20%20%7B%0A%20%20%20%20println%21%28%22%7B%7D%22%2C%20true%20%3D%3D%20true%29%3B%0A%20%20%20%20println%21%28%22%7B%7D%22%2C%20true%20%3D%3D%20false%29%3B%0A%20%20%20%20println%21%28%22%7B%7D%22%2C%20true%20%21%3D%20false%29%3B%0A%7D)

Но не стоит воспринимать `true` и `false` как обычные числа.

Например, такой стиль рассуждения:

```text
true = 1
false = 0
```

не является моделью типов Rust.

`bool` — самостоятельный тип.

# 4.5. Результат сравнения можно сохранить

Поскольку сравнение является выражением, его результат можно сохранить в binding:

```rust
fn main() {
    let age = 25;
    let adult = age >= 18;

    println!("Adult: {adult}");
}
```

[▶ Открыть пример в Rust Playground](https://play.rust-lang.org/?version=stable&mode=debug&edition=2024&code=fn%20main%28%29%20%20%7B%0A%20%20%20%20let%20age%20%3D%2025%3B%0A%20%20%20%20let%20adult%20%3D%20age%20%3E%3D%2018%3B%0A%0A%20%20%20%20println%21%28%22Adult%3A%20%7Badult%7D%22%29%3B%0A%7D)

Здесь происходит несколько действий:

1. `age` получает значение `25`;
2. выполняется `age >= 18`;
3. результатом становится `true`;
4. `true` сохраняется в `adult`;
5. `adult` используется дальше.

Так постепенно формируется настоящая программа, а не просто последовательность вычислений.

# 4.6. Логические операторы

Одного условия часто недостаточно.

Например:

```text
температура выше 0
И
температура ниже 30
```

Для объединения логических значений Rust предоставляет три основных оператора:

| Оператор | Название | Значение |
| -------- | -------- | -------- |
| `!`      | NOT      | НЕ       |
| `&&`     | AND      | И        |
| `\|\|`   | OR       | ИЛИ      |

---

# 4.7. Оператор `!`

`!` меняет логическое значение на противоположное:

```rust
fn main() {
    let value = true;

    println!("{value}");
    println!("{}", !value);
    println!("{}", !!value);
}
```

[▶ Открыть пример в Rust Playground](https://play.rust-lang.org/?version=stable&mode=debug&edition=2024&code=fn%20main%28%29%20%20%7B%0A%20%20%20%20let%20value%20%3D%20true%3B%0A%0A%20%20%20%20println%21%28%22%7Bvalue%7D%22%29%3B%0A%20%20%20%20println%21%28%22%7B%7D%22%2C%20%21value%29%3B%0A%20%20%20%20println%21%28%22%7B%7D%22%2C%20%21%21value%29%3B%0A%7D)

Можно читать:

```rust
!value
```

как:

> «не `value`».

# 4.8. Оператор `&&`

Оператор `&&` означает **логическое И**.

Результат будет `true` только тогда, когда оба выражения имеют значение `true`.

```rust
fn main() {
    let a = true;
    let b = false;

    println!("{}", a && a);
    println!("{}", a && b);
    println!("{}", b && a);
    println!("{}", b && b);
}
```

[▶ Открыть пример в Rust Playground](https://play.rust-lang.org/?version=stable&mode=debug&edition=2024&code=fn%20main%28%29%20%20%7B%0A%20%20%20%20let%20a%20%3D%20true%3B%0A%20%20%20%20let%20b%20%3D%20false%3B%0A%0A%20%20%20%20println%21%28%22%7B%7D%22%2C%20a%20%26%26%20a%29%3B%0A%20%20%20%20println%21%28%22%7B%7D%22%2C%20a%20%26%26%20b%29%3B%0A%20%20%20%20println%21%28%22%7B%7D%22%2C%20b%20%26%26%20a%29%3B%0A%20%20%20%20println%21%28%22%7B%7D%22%2C%20b%20%26%26%20b%29%3B%0A%7D)

Удобно представить таблицу истинности:

| `a`     | `b`     | `a && b` |
| ------- | ------- | -------- |
| `false` | `false` | `false`  |
| `false` | `true`  | `false`  |
| `true`  | `false` | `false`  |
| `true`  | `true`  | `true`   |

# 4.9. Оператор `||`

`||` означает **логическое ИЛИ**.

Результат будет `true`, если хотя бы одно из выражений равно `true`.

```rust
fn main() {
    let a = true;
    let b = false;

    println!("{}", a || a);
    println!("{}", a || b);
    println!("{}", b || a);
    println!("{}", b || b);
}
```

| `true`  | `false` | `true`     |
| `true`  | `true`  | `true`     |

# 4.10. Комбинирование условий

```rust
fn main() {
    let temperature = 25;

    let comfortable = temperature >= 18 && temperature <= 28;

    println!("Comfortable: {comfortable}");
}
```

## 4.11. Порядок вычисления логических операторов

Когда в выражении встречается несколько операторов, важен их приоритет.

Для логических операторов порядок такой (от высшего к низшему):

```text
!
&&
||
```

То есть `!` выполняется раньше `&&`, а `&&` — раньше `||`.

Пример:

```rust
fn main() {
    let a = true;
    let b = false;

    println!("{}", a || b && !a);
}
```

[▶ Открыть пример в Rust Playground](https://play.rust-lang.org/?version=stable&mode=debug&edition=2024&code=fn%20main%28%29%20%7B%0A%20%20%20%20let%20a%20%3D%20true%3B%0A%20%20%20%20let%20b%20%3D%20false%3B%0A%0A%20%20%20%20println%21%28%22%7B%7D%22%2C%20a%20%7C%7C%20b%20%26%26%20%21a%29%3B%0A%7D)

Фактически выражение интерпретируется как:

```rust
a || (b && (!a))
```

Результат: `true`.

Но не стоит заставлять читателя постоянно помнить таблицу приоритетов.

**Скобки делают намерение программы очевидным.**

```rust
fn main() {
    let a = true;
    let b = false;

    println!("{}", (a || b) && !a);
}
```

[▶ Открыть пример в Rust Playground](https://play.rust-lang.org/?version=stable&mode=debug&edition=2024&code=fn%20main%28%29%20%7B%0A%20%20%20%20let%20a%20%3D%20true%3B%0A%20%20%20%20let%20b%20%3D%20false%3B%0A%0A%20%20%20%20println%21%28%22%7B%7D%22%2C%20%28a%20%7C%7C%20b%29%20%26%26%20%21a%29%3B%0A%7D)

В реальном коде скобки часто полезны не потому, что без них программа не работает, а потому, что **читающий код человек сразу понимает намерение автора**.

## 4.12. Короткое замыкание (short-circuit evaluation)

У операторов `&&` и `||` есть важная особенность: Rust не всегда вычисляет оба операнда.

- Для `&&`: если левая часть равна `false`, правую часть можно не вычислять — результат всё равно будет `false`.
- Для `||`: если левая часть равна `true`, правую часть можно не вычислять — результат всё равно будет `true`.

Пример:

```rust
fn main() {
    let first = false && {
        println!("This will not be printed");
        true
    };

    let second = true || {
        println!("This will not be printed");
        false
    };

    println!("first = {first}");
    println!("second = {second}");
}
```

[▶ Открыть пример в Rust Playground](https://play.rust-lang.org/?version=stable&mode=debug&edition=2024&code=fn%20main%28%29%20%7B%0A%20%20%20%20let%20first%20%3D%20false%20%26%26%20%7B%0A%20%20%20%20%20%20%20%20println%21%28%22This%20will%20not%20be%20printed%22%29%3B%0A%20%20%20%20%20%20%20%20true%0A%20%20%20%20%7D%3B%0A%0A%20%20%20%20let%20second%20%3D%20true%20%7C%7C%20%7B%0A%20%20%20%20%20%20%20%20println%21%28%22This%20will%20not%20be%20printed%22%29%3B%0A%20%20%20%20%20%20%20%20false%0A%20%20%20%20%7D%3B%0A%0A%20%20%20%20println%21%28%22first%20%3D%20%7Bfirst%7D%22%29%3B%0A%20%20%20%20println%21%28%22second%20%3D%20%7Bsecond%7D%22%29%3B%0A%7D)

Результат:

```text
first = false
second = true
```

Сообщения `"This will not be printed"` не появляются — правые части выражений не выполнялись.

Этот механизм называется **short-circuit evaluation** (сокращённое вычисление).

Пока достаточно запомнить его как полезное свойство `&&` и `||`. Позже оно станет особенно важным при проверке условий, работе с `Option`, `Result` и кодом, который может иметь побочные эффекты.

* short-circuit evaluation;
* сохранение результата сравнения в binding.

Самая важная новая идея:

> **логическое выражение — это обычное выражение Rust, результатом которого является `bool`.**

Например:

```rust
let adult = age >= 18;
```

Здесь `age >= 18` не является каким-то специальным «условием». Это выражение, вычисляющее значение `bool`.

А значит, теперь мы готовы сделать следующий шаг:

```rust
if adult {
    // ...
}
```
