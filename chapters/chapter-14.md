# Глава 14. Срезы и строки

В предыдущих главах мы научились работать с массивами и векторами, а также с владением и заимствованием. Теперь пришло время объединить эти знания и познакомиться с двумя очень важными концепциями Rust: **срезами (slices)** и **строками (strings)**.

Срезы позволяют нам ссылаться на часть коллекции, не копируя её. А строки в Rust — это одна из самых частых тем, вызывающих вопросы у новичков. В этой главе мы разберёмся, что такое `String`, `&str`, почему строки нельзя индексировать как массивы, и как эффективно работать с текстом в Rust.

Все примеры этой главы используют **Rust Edition 2024** и подготовлены для запуска непосредственно в [Rust Playground](https://play.rust-lang.org/).

---

## 14.1. Что такое срез (slice)?

**Срез (slice)** — это ссылка на непрерывную последовательность элементов в коллекции. Срез не владеет данными — он лишь заимствует их.

Синтаксис срезов: `&[T]` для среза массива или вектора.

```rust
fn main() {
    let arr = [1, 2, 3, 4, 5];
    let slice = &arr[1..4]; // срез элементов с индексами 1, 2, 3

    println!("slice: {:?}", slice); // [2, 3, 4]
}
```

[▶ Открыть пример в Rust Playground](https://play.rust-lang.org/?version=stable&mode=debug&edition=2024&code=fn%20main%28%29%20%7B%0A%20%20%20%20let%20arr%20%3D%20%5B1%2C%202%2C%203%2C%204%2C%205%5D%3B%0A%20%20%20%20let%20slice%20%3D%20%26arr%5B1..4%5D%3B%0A%0A%20%20%20%20println%21%28%22slice%3A%20%7B%3A%3F%7D%22%2C%20slice%29%3B%0A%7D)

**Что такое `&arr[1..4]`?**

- `arr[1..4]` — диапазон индексов от 1 до 4 (не включая 4).
- `&` — создаёт ссылку на эти элементы.
- Результат: срез типа `&[i32]`.

## 14.2. Срезы массивов и векторов

Срезы работают одинаково для массивов и векторов:

```rust
fn main() {
    let arr = [10, 20, 30, 40, 50];
    let vec = vec![1, 2, 3, 4, 5];

    let arr_slice = &arr[1..4];
    let vec_slice = &vec[0..3];

    println!("arr_slice: {:?}", arr_slice); // [20, 30, 40]
    println!("vec_slice: {:?}", vec_slice); // [1, 2, 3]
}
```

## 14.4. Срезы и функции

Срезы позволяют писать функции, работающие с любой коллекцией:

```rust
fn sum_slice(slice: &[i32]) -> i32 {
    let mut sum = 0;
    for &num in slice {
        sum += num;
    }
    sum
}

fn main() {
    let arr = [1, 2, 3, 4, 5];
    let vec = vec![10, 20, 30];

    println!("{}", sum_slice(&arr));      // 15
    println!("{}", sum_slice(&vec));      // 60
    println!("{}", sum_slice(&arr[1..4])); // 9
}
```

Функция принимает `&[i32]` — срез целых чисел. Она работает с массивами, векторами и другими срезами.

## 14.5. Строки в Rust: два типа

В Rust существует два основных типа для работы с текстом:

| Тип      | Описание                            | Владение          |
| -------- | ----------------------------------- | ----------------- |
| `String` | Изменяемая, владеющая строка в куче | Владеет данными   |
| `&str`   | Неизменяемая ссылка на строку       | Заимствует данные |

---

## 14.6. Что такое `&str`?

`&str` — это строковый срез. Это ссылка на последовательность UTF-8 символов, которая может находиться:

1. В статической памяти программы (строковые литералы).
2. Как часть `String`.
3. Как часть другой строки.

```rust
fn main() {
    let s: &str = "Hello, world!"; // строковый литерал — это &'static str
    println!("{}", s);
}
```

---

## 14.7. Что такое `String`?

`String` — это изменяемая, владеющая строка, которая хранится в куче:

```rust
fn main() {
    let mut s = String::from("Hello");
    s.push_str(", world!"); // изменяем
    println!("{}", s);
}
```

## 14.8. Преобразование между `String` и `&str`

```rust
fn main() {
    // &str → String
    let s1: String = String::from("hello");
    let s2: String = "hello".to_string();

    // String → &str
    let s3: String = String::from("hello");
    let s4: &str = &s3; // автоматическое преобразование
    let s5: &str = s3.as_str();

    println!("{} {} {} {}", s1, s2, s4, s5);
}
```

## 14.9. Почему строки нельзя индексировать как массив?

В Rust строки хранятся в кодировке UTF-8. Один символ может занимать разное количество байт:

```rust
fn main() {
    let s = "Привет"; // кириллица — 2 байта на символ

    // Не работает!
    // let first = s[0]; // ❌ Ошибка!

    // Правильный способ:
    let first_char = s.chars().next();
    println!("{:?}", first_char); // Some('П')
}
```

[▶ Открыть пример в Rust Playground](https://play.rust-lang.org/?version=stable&mode=debug&edition=2024&code=fn%20main%28%29%20%7B%0A%20%20%20%20let%20s%20%3D%20%22%D0%9F%D1%80%D0%B8%D0%B2%D0%B5%D1%82%22%3B%0A%0A%20%20%20%20let%20first_char%20%3D%20s.chars%28%29.next%28%29%3B%0A%20%20%20%20println%21%28%22%7B%3A%3F%7D%22%2C%20first_char%29%3B%0A%7D)

**Почему так?**

- В UTF-8 символы имеют переменную длину (1–4 байта).
- `s[0]` не может вернуть символ — непонятно, сколько байт читать.
- Rust не делает предположений и требует явного указания, как работать со строками.

## 14.10. Итерация по строкам: `chars()` и `bytes()`

```rust
fn main() {
    let s = "Hello, 世界";

    // Итерация по символам (Unicode scalar values)
    println!("Characters:");
    for c in s.chars() {
        print!("{} ", c);
    }
    println!();

    // Итерация по байтам (UTF-8 encoding)
    println!("Bytes:");
    for b in s.bytes() {
        print!("{} ", b);
    }
    println!();

    // Длина в байтах
    println!("Bytes length: {}", s.len());

    // Количество символов
    println!("Chars count: {}", s.chars().count());
}
```

## 14.11. Срезы строк

Строковые срезы работают только на границах UTF-8 символов:

```rust
fn main() {
    let s = "Hello, world!";
    let slice = &s[0..5]; // "Hello" — безопасно
    println!("{}", slice);
}
```

[▶ Открыть пример в Rust Playground](https://play.rust-lang.org/?version=stable&mode=debug&edition=2024&code=fn%20main%28%29%20%7B%0A%20%20%20%20let%20s%20%3D%20%22Hello%2C%20world%21%22%3B%0A%0A%20%20%20%20let%20slice%20%3D%20%26s%5B0..5%5D%3B%0A%20%20%20%20println%21%28%22%7B%7D%22%2C%20slice%29%3B%0A%7D)

С многобайтовыми символами нужно быть осторожнее. Каждая базовая кириллическая буква в UTF-8 занимает 2 байта, поэтому в `"Привет"` границы символов проходят на смещениях `0, 2, 4, 6, 8, 10, 12`. Срез `&s2[0..2]` безопасен:

```rust
fn main() {
    let s2 = "Привет";
    let slice2 = &s2[0..2]; // "П" — граница символа
    println!("{}", slice2);
}
```

[▶ Открыть пример в Rust Playground](https://play.rust-lang.org/?version=stable&mode=debug&edition=2024&code=fn%20main%28%29%20%7B%0A%20%20%20%20let%20s2%20%3D%20%22%D0%9F%D1%80%D0%B8%D0%B2%D0%B5%D1%82%22%3B%0A%20%20%20%20let%20slice2%20%3D%20%26s2%5B0..2%5D%3B%0A%20%20%20%20println%21%28%22%7B%7D%22%2C%20slice2%29%3B%0A%7D)

А срез, разрезающий символ пополам, паникует:

```rust
fn main() {
    let s2 = "Привет";
    let slice2 = &s2[0..1]; // паника: середина символа "П"
    println!("{}", slice2);
}
```

[▶ Открыть пример с ошибкой в Rust Playground](https://play.rust-lang.org/?version=stable&mode=debug&edition=2024&code=fn%20main%28%29%20%7B%0A%20%20%20%20let%20s2%20%3D%20%22%D0%9F%D1%80%D0%B8%D0%B2%D0%B5%D1%82%22%3B%0A%20%20%20%20let%20slice2%20%3D%20%26s2%5B0..1%5D%3B%0A%20%20%20%20println%21%28%22%7B%7D%22%2C%20slice2%29%3B%0A%7D)

Программа компилируется, но паникует: `byte index 1 is not a char boundary`.

**Важно:** срез строки должен приходиться на границу символа UTF-8. Для ASCII это 1 байт, для кириллицы обычно 2, для большинства иероглифов — 3.

## 14.12. Владение строками: `String` vs `&str`

```rust
fn takes_string(s: String) {
    println!("{}", s);
} // s уничтожается

fn takes_str(s: &str) {
    println!("{}", s);
} // s — ссылка, владение не забирается

fn main() {
    let s = String::from("hello");

    takes_str(&s); // заимствование
    println!("{}", s); // s всё ещё доступен

    takes_string(s); // владение перемещается
    // println!("{}", s); // ошибка! s больше не владеет значением
}
```

**Правило:**

- Используйте `&str` для параметров, если функция не должна владеть строкой.
- Используйте `String` когда нужно владеть и изменять строку.

## 14.13. Преимущества `&str` перед `&String`

В Rust принято использовать `&str` вместо `&String` в параметрах функций:

```rust
// ✅ Лучше
fn print_slice(s: &str) {
    println!("{}", s);
}

// ❌ Хуже (менее гибко)
fn print_string(s: &String) {
    println!("{}", s);
}

fn main() {
    let s = String::from("hello");
    print_slice(&s); // работает
    print_slice("world"); // работает

    print_string(&s); // работает
    // print_string("world"); // ❌ не работает! ожидается &String
}
```

[▶ Открыть пример в Rust Playground](https://play.rust-lang.org/?version=stable&mode=debug&edition=2024&code=fn%20print_slice%28s%3A%20%26str%29%20%7B%0A%20%20%20%20println%21%28%22%7B%7D%22%2C%20s%29%3B%0A%7D%0A%0Afn%20print_string%28s%3A%20%26String%29%20%7B%0A%20%20%20%20println%21%28%22%7B%7D%22%2C%20s%29%3B%0A%7D%0A%0Afn%20main%28%29%20%7B%0A%20%20%20%20let%20s%20%3D%20String%3A%3Afrom%28%22hello%22%29%3B%0A%20%20%20%20print_slice%28%26s%29%3B%0A%20%20%20%20print_slice%28%22world%22%29%3B%0A%0A%20%20%20%20print_string%28%26s%29%3B%0A%7D)

`&str` принимает и `String` (через `&String`) и строковые литералы (`"hello"`). Это делает функции более универсальными.

## 14.14. Другие строковые типы: `OsString`, `PathBuf`

В Rust есть специализированные строковые типы для работы с операционной системой:

| Тип        | Владение   | Назначение                   |
| ---------- | ---------- | ---------------------------- |
| `OsStr`    | Заимствует | Строки ОС (разные кодировки) |
| `OsString` | Владеет    | Строки ОС (разные кодировки) |
| `Path`     | Заимствует | Пути к файлам и директориям  |
| `PathBuf`  | Владеет    | Пути к файлам и директориям  |

```rust
use std::path::Path;

fn main() {
    let path = Path::new("/home/user/file.txt");
    println!("File name: {:?}", path.file_name());
}
```

Эти типы важны для кросс-платформенных приложений, но выходят за рамки этой главы.

## Главное из этой главы

После этой главы мы понимаем:

- **Срезы (`&[T]`)** — ссылки на часть коллекции без копирования.
- **Срезы работают с массивами и векторами**.
- **Строки в Rust — это UTF-8**.
- **`String`** — владеющая, изменяемая строка в куче.
- **`&str`** — заимствуемый, неизменяемый строковый срез.
- **Строки нельзя индексировать** как массивы, потому что символы UTF-8 имеют переменную длину.
- Для итерации по символам используйте `.chars()`, по байтам — `.bytes()`.
- **В параметрах функций используйте `&str` вместо `&String`** — это более гибко.

**Самая важная идея:**

> Срезы и строки в Rust — это пример того, как владение и заимствование работают на практике. Они позволяют эффективно работать с данными без копирования, сохраняя безопасность памяти.
