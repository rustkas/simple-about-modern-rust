# Глава 6. Функции

До этого момента весь наш код помещался в функцию `main`. Это было удобно для экспериментов, но любой реальный проект быстро становится слишком сложным для одной большой функции.

Функции — это главный способ **организовать код**, разбить его на небольшие, понятные и переиспользуемые части. Они позволяют дать имя блоку кода, вызывать его многократно и, что самое важное, скрыть детали реализации.

В этой главе мы узнаем, как создавать и использовать функции в Rust, и познакомимся с несколькими ключевыми идеями, которые делают Rust особенным.

Все примеры этой главы используют **Rust Edition 2024** и подготовлены для запуска непосредственно в [Rust Playground](https://play.rust-lang.org/).

---

## 6.1. Определение и вызов функции

Функция в Rust определяется с помощью ключевого слова `fn`. Она имеет имя, параметры (если они есть) и тело, заключённое в фигурные скобки.

```rust
fn greet() {
    println!("Hello, world!");
}

fn main() {
    greet();
    greet();
}
```

[▶ Открыть пример в Rust Playground](https://play.rust-lang.org/?version=stable&mode=debug&edition=2024&code=fn%20greet%28%29%20%7B%0A%20%20%20%20println%21%28%22Hello%2C%20world%21%22%29%3B%0A%7D%0A%0Afn%20main%28%29%20%7B%0A%20%20%20%20greet%28%29%3B%0A%20%20%20%20greet%28%29%3B%0A%7D)

Результат:

```text
Hello, world!
Hello, world!
```

Этот пример демонстрирует две вещи:

1. Функция `greet` вызывается дважды из `main`.
2. Код в `greet` может быть выполнен многократно без дублирования.

## 6.2. Параметры функций

Функции могут принимать **параметры** — значения, которые передаются в функцию при её вызове. Параметры — это часть **сигнатуры функции**.

```rust
fn greet(name: &str) {
    println!("Hello, {}!", name);
}

fn main() {
    greet("Alice");
    greet("Bob");
}
```

[▶ Открыть пример в Rust Playground](https://play.rust-lang.org/?version=stable&mode=debug&edition=2024&code=fn%20greet%28name%3A%20%26str%29%20%7B%0A%20%20%20%20println%21%28%22Hello%2C%20%7B%7D%21%22%2C%20name%29%3B%0A%7D%0A%0Afn%20main%28%29%20%7B%0A%20%20%20%20greet%28%22Alice%22%29%3B%0A%20%20%20%20greet%28%22Bob%22%29%3B%0A%7D)

Здесь у функции `greet` один параметр `name` типа `&str` (строковый срез). При вызове `greet("Alice")` значение `"Alice"` передается в параметр `name` внутри функции.

---

## 6.3. Почему Rust требует указывать тип параметров?

В отличие от некоторых языков, Rust **требует явно указывать тип каждого параметра** функции.

```rust
// Это правильно
fn add(a: i32, b: i32) -> i32 {
    a + b
}

// А это вызовет ошибку компиляции
// fn add_wrong(a, b) {
//     a + b
// }
```

Такое требование — часть философии Rust. Это делает код самодокументируемым и позволяет компилятору точно знать, какой тип данных обрабатывается. Указание типов — это явный контракт, который гарантирует, что функция будет работать с ожидаемыми данными.

## 6.4. 🔨 Сломайте код: Неправильный тип

Что произойдет, если передать в функцию значение неправильного типа?

```rust
fn greet(name: &str) {
    println!("Hello, {}!", name);
}

fn main() {
    greet(42);
}
```

[▶ Открыть пример с ошибкой в Rust Playground](https://play.rust-lang.org/?version=stable&mode=debug&edition=2024&code=fn%20greet%28name%3A%20%26str%29%20%7B%0A%20%20%20%20println%21%28%22Hello%2C%20%7B%7D%21%22%2C%20name%29%3B%0A%7D%0A%0Afn%20main%28%29%20%7B%0A%20%20%20%20greet%2842%29%3B%0A%7D)

Компилятор сообщит об ошибке несоответствия типов: ожидался `&str`, а найдено целое число. Это защищает программу от ошибок, которые в языках с динамической типизацией проявились бы только во время выполнения.

## 6.5. Возвращаемое значение

Функции могут возвращать значения. Тип возвращаемого значения указывается после стрелки `->`.

```rust
fn add(a: i32, b: i32) -> i32 {
    a + b   // последнее выражение возвращается
}

fn main() {
    let sum = add(5, 3);
    println!("5 + 3 = {}", sum);
}
```

[▶ Открыть пример в Rust Playground](https://play.rust-lang.org/?version=stable&mode=debug&edition=2024&code=fn%20add%28a%3A%20i32%2C%20b%3A%20i32%29%20-%3E%20i32%20%7B%0A%20%20%20%20a%20%2B%20b%0A%7D%0A%0Afn%20main%28%29%20%7B%0A%20%20%20%20let%20sum%20%3D%20add%285%2C%203%29%3B%0A%20%20%20%20println%21%28%225%20%2B%203%20%3D%20%7B%7D%22%2C%20sum%29%3B%0A%7D)

Результат:

```text
5 + 3 = 8
```

В Rust **нет обязательного ключевого слова `return`** для возврата значения из функции. Вместо этого возвращается значение **последнего выражения** в функции (без точки с запятой). Это важное отличие, которое подчёркивает, что Rust — язык выражений.

Ключевое слово `return` существует и используется для **досрочного** выхода из функции (см. следующий раздел).

## 6.6. Выражения и операторы

Чтобы понять, как работают функции, важно различать выражения и операторы (statements).

- **Оператор (statement)** — инструкция, которая выполняет действие, но не возвращает значение. Обычно заканчивается точкой с запятой `;`. Пример: `let x = 5;`.
- **Выражение (expression)** — фрагмент кода, который вычисляется и **возвращает значение**. Не заканчивается точкой с запятой. Пример: `5 + 3` или `a + b`.

Тело функции — это блок кода, и оно само является выражением. Значение последнего выражения в блоке становится значением всего блока (и, соответственно, возвращаемым значением функции).

```rust
fn main() {
    let y = {
        let x = 3;   // оператор
        x + 1        // выражение → значение блока
    };

    println!("y = {}", y);
}
```

[▶ Открыть пример в Rust Playground](https://play.rust-lang.org/?version=stable&mode=debug&edition=2024&code=fn%20main%28%29%20%7B%0A%20%20%20%20let%20y%20%3D%20%7B%0A%20%20%20%20%20%20%20%20let%20x%20%3D%203%3B%0A%20%20%20%20%20%20%20%20x%20%2B%201%0A%20%20%20%20%7D%3B%0A%0A%20%20%20%20println%21%28%22y%20%3D%20%7B%7D%22%2C%20y%29%3B%0A%7D)

Результат:

```text
y = 4
```

Если поставить точку с запятой после `x + 1`, блок перестанет возвращать значение, и программа не скомпилируется (если от него ожидается результат).

## 6.7. `return` для досрочного возврата

Хотя последнее выражение — идиоматичный способ возврата, существует ключевое слово `return` для немедленного выхода из функции (часто в сочетании с условной логикой).

```rust
fn is_even(number: i32) -> bool {
    if number % 2 == 0 {
        return true;
    }
    false   // последнее выражение, если return не сработал
}

fn main() {
    println!("4 is even: {}", is_even(4));
    println!("7 is even: {}", is_even(7));
}
```

Результат:

```text
4 is even: true
7 is even: false
```

## 6.8. Функции, не возвращающие значение

Если функция не возвращает осмысленного значения, её тип возврата — `()` (unit type). Это можно указать явно:

```rust
fn do_nothing() -> () {
    // ничего не возвращает
}

fn main() {
    let result = do_nothing();
    println!("{:?}", result); // выведет ()
}
```

[▶ Открыть пример в Rust Playground](https://play.rust-lang.org/?version=stable&mode=debug&edition=2024&code=fn%20do_nothing%28%29%20-%3E%20%28%29%20%7B%0A%20%20%20%20%2F%2F%20%D0%BD%D0%B8%D1%87%D0%B5%D0%B3%D0%BE%20%D0%BD%D0%B5%20%D0%B2%D0%BE%D0%B7%D0%B2%D1%80%D0%B0%D1%89%D0%B0%D0%B5%D1%82%0A%7D%0A%0Afn%20main%28%29%20%7B%0A%20%20%20%20let%20result%20%3D%20do_nothing%28%29%3B%0A%20%20%20%20println%21%28%22%7B%3A%3F%7D%22%2C%20result%29%3B%0A%7D)

На практике указание `-> ()` почти всегда опускают. Функции без явного возвращаемого типа автоматически возвращают `()`.

## 6.9. Область видимости

Область видимости определяет, где в программе доступна переменная. Переменные, объявленные внутри функции, доступны только в этой функции. Параметры функции также находятся в её области видимости.

```rust
fn example() {
    let x = 10; // x доступна только здесь
    println!("{}", x);
}

fn main() {
    // println!("{}", x); // Ошибка! x не определена в этой области видимости
}
```

[▶ Открыть пример в Rust Playground](https://play.rust-lang.org/?version=stable&mode=debug&edition=2024&code=fn%20example%28%29%20%7B%0A%20%20%20%20let%20x%20%3D%2010%3B%0A%20%20%20%20println%21%28%22%7B%7D%22%2C%20x%29%3B%0A%7D%0A%0Afn%20main%28%29%20%7B%0A%20%20%20%20example%28%29%3B%0A%20%20%20%20%2F%2F%20println%21%28%22%7B%7D%22%2C%20x%29%3B%0A%7D)

Раскомментируйте последнюю строку, чтобы увидеть ошибку компилятора. Это базовое правило изоляции данных — одна из основ безопасности в Rust.

## 6.11. Рекурсия

Функции могут вызывать сами себя — это называется рекурсией. Это мощный, но иногда опасный инструмент. В Rust рекурсия работает так же, как и в других языках, но нужно быть осторожным с глубиной рекурсии, чтобы не переполнить стек.

```rust
fn factorial(n: u64) -> u64 {
    if n <= 1 {
        1
    } else {
        n * factorial(n - 1)
    }
}

fn main() {
    println!("5! = {}", factorial(5));
}
```

## 6.12. Функции и выражения: `if`, `match` и блоки

Поскольку `if`, `match` и блоки являются выражениями, их можно использовать для возврата значений из функций.

```rust
fn get_message(level: u8) -> String {
    if level > 5 {
        String::from("High")
    } else {
        String::from("Low")
    }
}

fn main() {
    println!("Message: {}", get_message(3));
    println!("Message: {}", get_message(7));
}
```

[▶ Открыть пример в Rust Playground](https://play.rust-lang.org/?version=stable&mode=debug&edition=2024&code=fn%20get_message%28level%3A%20u8%29%20-%3E%20String%20%7B%0A%20%20%20%20if%20level%20%3E%205%20%7B%0A%20%20%20%20%20%20%20%20String%3A%3Afrom%28%22High%22%29%0A%20%20%20%20%7D%20else%20%7B%0A%20%20%20%20%20%20%20%20String%3A%3Afrom%28%22Low%22%29%0A%20%20%20%20%7D%0A%7D%0A%0Afn%20main%28%29%20%7B%0A%20%20%20%20println%21%28%22Message%3A%20%7B%7D%22%2C%20get_message%283%29%29%3B%0A%20%20%20%20println%21%28%22Message%3A%20%7B%7D%22%2C%20get_message%287%29%29%3B%0A%7D)

Результат:

```text
Message: Low
Message: High
```

Здесь `String::from("High")` создаёт **владеющую** строку. В отличие от `&str`, с которым мы работали раньше, `String` сам является хозяином текста. Разницу между `&str` и `String`, а также идею владения (ownership) мы подробно разберём в следующих главах. Пока достаточно запомнить: если функция должна **создать и вернуть** текст, `String` — естественный и безопасный выбор.

## Главное из этой главы

После этой главы мы умеем:

- Определять функции с помощью `fn`.
- Передавать функции **параметры** с явным указанием типа.
- Возвращать значения из функций, используя **последнее выражение**.
- Использовать `return` для досрочного возврата.
- Понимать разницу между **выражениями** и **операторами**.
- Видеть, как блоки кода, `if` и `match` могут использоваться как выражения.
- Осознавать, что **явная типизация параметров** — это сознательное решение Rust, а не недостаток.
- Писать рекурсивные функции.
