# Глава 2. Значения, типы и выражения

В первой главе мы познакомились с Rust и научились запускать простейшие программы.

Теперь начнём разбираться с тем, **что именно вычисляет программа**.

Практически любая программа работает со значениями:

```text
числа
текст
символы
логические значения
```

Rust при этом должен знать, **какого типа является каждое значение**.

А когда над значениями выполняется операция, возникает **выражение**.

Поэтому основная идея этой главы:

```text
значение
    ↓
тип
    ↓
операция
    ↓
выражение
    ↓
результат
```

Как и раньше, мы не будем просто читать описание языка. Большинство примеров можно сразу открыть в **Rust Playground**, запустить, изменить и снова запустить.

Все примеры этой книги используют **stable Rust**, **debug mode** и **edition 2024**.

---

## 2.1. Значение

Начнём с простого числа:

```rust
42
```

`42` — это значение.

Другими значениями могут быть:

```text
3.14
true
'A'
"Hello"
```

На первый взгляд между ними мало общего. Но для Rust это разные виды значений.

Попробуем вывести их:

```rust
fn main() {
    println!("{}", 42);
    println!("{}", 3.14);
    println!("{}", true);
    println!("{}", 'A');
    println!("{}", "Hello");
}
```

[▶ Открыть пример в Rust Playground](https://play.rust-lang.org/?version=stable&mode=debug&edition=2024&code=fn%20main%28%29%20%7B%0A%20%20%20%20println%21%28%22%7B%7D%22%2C%2042%29%3B%0A%20%20%20%20println%21%28%22%7B%7D%22%2C%203.14%29%3B%0A%20%20%20%20println%21%28%22%7B%7D%22%2C%20true%29%3B%0A%20%20%20%20println%21%28%22%7B%7D%22%2C%20%27A%27%29%3B%0A%20%20%20%20println%21%28%22%7B%7D%22%2C%20%22Hello%22%29%3B%0A%7D)

После запуска мы увидим:

```text
42
3.14
true
A
Hello
```

Попробуйте самостоятельно изменить значения.

Например:

```rust
println!("{}", 100);
println!("{}", false);
println!("{}", 'R');
println!("{}", "Rust");
```

Обратите внимание: `println!` здесь используется только как удобный способ посмотреть на результат вычисления. Самое интересное в этих примерах — не `println!`, а значения, которые мы ему передаём.

## 2.2. Значение имеет тип

Теперь возникает важный вопрос:

> Откуда Rust знает, что `42` — это число, а `"Hello"` — текст?

У каждого значения есть **тип**.

Например:

```text
42       → целое число
3.14     → число с плавающей точкой
true     → логическое значение
'A'      → символ
"Hello"  → строковый литерал
```

Тип определяет, какие операции можно выполнять со значением.

Два числа можно сложить:

```rust
2 + 3
```

А попытка сложить число и логическое значение не имеет смысла:

```rust
2 + true
```

Проверим это непосредственно в компиляторе:

```rust
fn main() {
    println!("{}", 2 + true);
}
```

[▶ Открыть пример в Rust Playground](https://play.rust-lang.org/?version=stable&mode=debug&edition=2024&code=fn%20main%28%29%20%7B%0A%20%20%20%20println%21%28%22%7B%7D%22%2C%202%20%2B%20true%29%3B%0A%7D)

Этот пример **не скомпилируется**.

Это важная особенность Rust: **типовая ошибка обнаруживается до запуска программы**.

## 2.3. Целые числа

Для работы с целыми числами Rust предоставляет несколько типов:

```text
i8
i16
i32
i64
i128
isize

u8
u16
u32
u64
u128
usize
```

Буква `i` означает signed integer — целое число со знаком.

Буква `u` означает unsigned integer — целое число без знака.

Например:

```text
i32
```

может хранить как положительные, так и отрицательные значения.

А:

```text
u32
```

предназначен только для неотрицательных значений.

### Пример для любознактельных\*

> программа, которая приводит текстовое представление целого числа последовательно к всем возможно типам цылых чисел

Программа принимает строковое представление целого числа и последовательно пытается преобразовать его во все стандартные целочисленные типы со знаком (`i8` — `isize`) и без знака (`u8` — `usize`), используя метод `parse()`.

#### Код программы на Rust

```rust
fn main() {
    let input_str = "42";

    println!("Парсим строку: \"{}\"\n", input_str);

    parse_and_print::<i8>(input_str, "i8");
    parse_and_print::<i16>(input_str, "i16");
    parse_and_print::<i32>(input_str, "i32");
    parse_and_print::<i64>(input_str, "i64");
    parse_and_print::<i128>(input_str, "i128");
    parse_and_print::<isize>(input_str, "isize");

    println!("----------------------------------------");

    parse_and_print::<u8>(input_str, "u8");
    parse_and_print::<u16>(input_str, "u16");
    parse_and_print::<u32>(input_str, "u32");
    parse_and_print::<u64>(input_str, "u64");
    parse_and_print::<u128>(input_str, "u128");
    parse_and_print::<usize>(input_str, "usize");
}

fn parse_and_print<T>(s: &str, type_name: &str)
where
    T: std::str::FromStr + std::fmt::Debug,
    <T as std::str::FromStr>::Err: std::fmt::Debug,
{
    match s.parse::<T>() {
        Ok(val) => println!("{}: Успешно -> {:?}", type_name, val),
        Err(e) => println!("{}: Ошибка парсинга -> {:?}", type_name, e),
    }
}

```

## 2.3.1. Обычное целое число

Если мы напишем:

```rust
fn main() {
    let x = 42;

    println!("{}", x);
}
```

[▶ Открыть пример в Rust Playground](https://play.rust-lang.org/?version=stable&mode=debug&edition=2024&code=fn+main%28%29+%7B%0A++++let+x+%3D+42%3B%0A%0A++++println%21%28%22%7B%7D%22%2C+x%29%3B%0A%7D)

Rust должен определить тип литерала `42`.

В данном контексте компилятор может использовать `i32` как тип по умолчанию.

Здесь мы пока не будем подробно разбирать `let`. Нам важно другое: числовой литерал `42` может использоваться без явного указания типа.

---

### 2.3.2. Явное указание типа

Мы можем указать тип самостоятельно:

```rust
fn main() {
    let x: i64 = 42;
    let y: u8 = 42;

    println!("{}", x);
    println!("{}", y);
}
```

[▶ Открыть пример в Rust Playground](https://play.rust-lang.org/?version=stable&mode=debug&edition=2024&code=fn%20main%28%29%20%7B%0A%20%20%20%20let%20x%3A%20i64%20%3D%2042%3B%0A%20%20%20%20let%20y%3A%20u8%20%3D%2042%3B%0A%0A%20%20%20%20println%21%28%22%7B%7D%22%2C%20x%29%3B%0A%20%20%20%20println%21%28%22%7B%7D%22%2C%20y%29%3B%0A%7D)

Теперь Rust знает:

```text
x → i64
y → u8
```

Само число `42` при этом не изменилось.

Изменился **тип, в котором это значение рассматривается**.

## 2.4. Запись больших чисел

Большие числа быстро становятся неудобными для чтения:

```rust
1000000000
```

Rust позволяет использовать символ `_` внутри числового литерала:

```rust
1_000_000_000
```

Попробуем:

```rust
fn main() {
    println!("{}", 1_000_000);
    println!("{}", 1_000_000_000);
    println!("{}", 1_000_000_000_000i64);
}
```

[▶ Открыть пример в Rust Playground](https://play.rust-lang.org/?version=stable&mode=debug&edition=2024&code=fn%20main%28%29%20%7B%0A%20%20%20%20println%21%28%22%7B%7D%22%2C%201_000_000%29%3B%0A%20%20%20%20println%21%28%22%7B%7D%22%2C%201_000_000_000%29%3B%0A%20%20%20%20println%21%28%22%7B%7D%22%2C%201_000_000_000_000i64%29%3B%0A%7D)

Символ `_` не является частью значения. Он только делает исходный код более удобным для чтения.

Поэтому:

```text
1_000_000
```

и:

```text
1000000
```

представляют одно и то же число.

## 2.5. Другие системы счисления

Целые числа можно записывать не только в десятичной системе.

Например:

```rust
fn main() {
    println!("{}", 42);
    println!("{}", 0x2A);
    println!("{}", 0o52);
    println!("{}", 0b101010);
}
```


## 2.7. Арифметические выражения

Теперь мы можем перейти к основной теме главы.

Рассмотрим:

```rust
2 + 2
```

Это **выражение**.

Оно состоит из двух значений:

```text
2
2
```

и оператора:

```text
+
```

В результате вычисления выражение создаёт новое значение:

```text
2 + 2
  ↓
  4
```

Попробуем:

```rust
fn main() {
    println!("{}", 2 + 2);
}
```

[▶ Открыть пример в Rust Playground](https://play.rust-lang.org/?version=stable&mode=debug&edition=2024&code=fn%20main%28%29%20%7B%0A%20%20%20%20println%21%28%22%7B%7D%22%2C%202%20%2B%202%29%3B%0A%7D)

Результат:

```text
4
```

Это очень важная идея Rust:

> **Выражение вычисляется и имеет результат.**

Пока мы будем постепенно развивать это понятие.

## 2.8. Сложение и вычитание

Для сложения используется:

```text
+
```

Для вычитания:

```text
-
```

Например:

```rust
fn main() {
    println!("Сумма чисел равна {}", 2 + 2);
    println!("Разность чисел равна {}", 2 - 2);
}
```

[▶ Открыть пример в Rust Playground](https://play.rust-lang.org/?version=stable&mode=debug&edition=2024&code=fn%20main%28%29%20%7B%0A%20%20%20%20println%21%28%22%D0%A1%D1%83%D0%BC%D0%BC%D0%B0%20%D1%87%D0%B8%D1%81%D0%B5%D0%BB%20%D1%80%D0%B0%D0%B2%D0%BD%D0%B0%20%7B%7D%22%2C%202%20%2B%202%29%3B%0A%20%20%20%20println%21%28%22%D0%A0%D0%B0%D0%B7%D0%BD%D0%BE%D1%81%D1%82%D1%8C%20%D1%87%D0%B8%D1%81%D0%B5%D0%BB%20%D1%80%D0%B0%D0%B2%D0%BD%D0%B0%20%7B%7D%22%2C%202%20-%202%29%3B%0A%7D)

Во время работы программы Rust вычисляет выражения:


Получает:

```text

```

и передаёт эти значения в `println!`.

Попробуйте изменить программу:

```rust

```

## 2.9. Умножение и деление

## 2.10. Целочисленное деление

Это хороший момент для небольшого эксперимента.

```rust
fn main() {
    println!("{}", 5 / 2);
    println!("{}", 10 / 3);
    println!("{}", 20 / 6);
}
```

## 2.16. Почему возникает ошибка округления

Числа `f32` и `f64` представлены в двоичной системе с ограниченной точностью (стандарт IEEE 754).

Некоторые десятичные дроби невозможно представить в этой системе точно. Например, десятичное `0.1` не имеет конечного точного представления в двоичной системе, поэтому компьютер хранит ближайшее представимое значение.

То же самое происходит с `0.2`. После сложения результат может оказаться чуть-чуть отличающимся от математического `0.3`.

Посмотрим на это с большим количеством знаков:

```rust
fn main() {
    println!("{:.17}", 0.1_f64);
    println!("{:.17}", 0.2_f64);
    println!("{:.17}", 0.3_f64);
    println!("{:.17}", 0.1_f64 + 0.2_f64);
}
```

[▶ Открыть пример в Rust Playground](https://play.rust-lang.org/?version=stable&mode=debug&edition=2024&code=fn%20main%28%29%20%7B%0A%20%20%20%20println%21%28%22%7B%3A.17%7D%22%2C%200.1_f64%29%3B%0A%20%20%20%20println%21%28%22%7B%3A.17%7D%22%2C%200.2_f64%29%3B%0A%20%20%20%20println%21%28%22%7B%3A.17%7D%22%2C%200.3_f64%29%3B%0A%20%20%20%20println%21%28%22%7B%3A.17%7D%22%2C%200.1_f64%20%2B%200.2_f64%29%3B%0A%7D)

Здесь `{:.17}` просит вывести число с 17 знаками после точки. Подробный синтаксис форматирования мы разберём позже; сейчас нам важен только результат.

Становится заметно, что компьютер работает не с идеальными десятичными дробями, а с их приближёнными представлениями.

Для начала достаточно запомнить:

> **`f32` и `f64` представляют вещественные числа с ограниченной точностью.**  
> Поэтому сравнивать результаты вычислений с плавающей точкой через обычное `==` нужно осторожно.

## 2.20. Целочисленная и floating-point арифметика при делении на ноль

Сравним два выражения:

```rust
fn main() {

```

[▶ Открыть пример в Rust Playground](https://play.rust-lang.org/?version=stable&mode=debug&edition=2024&code=fn+main%28%29+%7B%0A++++println%21%28%22%7B%7D%22%2C+10.0+%2F+0.0%29%3B%0A++++println%21%28%22%7B%7D%22%2C+0.0+%2F+0.0%29%3B%0A%7D)

## 2.21. Типы определяют допустимые операции

Вернёмся к примеру:

```rust
2 + 2          // оба значения — целые числа → операция допустима
```

Теперь попробуем:

```rust
fn main() {
    println!("{}", 2 + 2.0);
}
```

[▶ Открыть пример в Rust Playground](https://play.rust-lang.org/?version=stable&mode=debug&edition=2024&code=fn%20main%28%29%20%7B%0A%20%20%20%20println%21%28%22%7B%7D%22%2C%202%20%2B%202.0%29%3B%0A%7D)

Этот код **не скомпилируется**.

Причина: Rust не выполняет произвольные неявные преобразования типов. Целое число (`i32` по умолчанию) и число с плавающей точкой (`f64`) — разные типы, и оператор `+` требует операндов одного типа.

## 2.22. Явное преобразование типов

Чтобы сложить целое и дробное число, нужно явно преобразовать один из операндов:

```rust
fn main() {
    let x: i32 = 2;
    let y: f64 = 2.0;

    let result = x as f64 + y;

    println!("{}", result);
}
```

[▶ Открыть пример в Rust Playground](https://play.rust-lang.org/?version=stable&mode=debug&edition=2024&code=fn+main%28%29+%7B%0A++++let+x%3A+i32+%3D+2%3B%0A++++let+y%3A+f64+%3D+2.0%3B%0A%0A++++let+result+%3D+x+as+f64+%2B+y%3B%0A++++%2F%2F+let+result+%3D+x+%2B+y+as+i32%3B%0A%0A++++println%21%28%22%7B%7D%22%2C+result%29%3B%0A%7D)

Здесь `x as f64` означает явное преобразование `x` в `f64`. После этого операция становится допустимой (`f64 + f64`).

Оператор `as` мы пока рассмотрели только на простом примере. Более подробно преобразования типов будут рассмотрены позже.

## 2.23. Вывод типов

Rust часто способен определить тип самостоятельно.

Например:

```rust
fn main() {
    let x = 42;

    let result = x + y;

    println!("{}", result);
}
```

[▶ Открыть пример в Rust Playground](https://play.rust-lang.org/?version=stable&mode=debug&edition=2024&code=fn%20main%28%29%20%7B%0A%20%20%20%20let%20x%20%3D%2042%3B%0A%20%20%20%20let%20y%20%3D%2010%3B%0A%0A%20%20%20%20let%20result%20%3D%20x%20%2B%20y%3B%0A%0A%20%20%20%20println%21%28%22%7B%7D%22%2C%20result%29%3B%0A%7D)

### Более точно решение такой задачи выглядит так*:

```rust
use std::any::type_name;

// Вспомогательная функция для вывода имени типа значения

}

fn main() {
    let x = 42;
    let y = 10;
    let result = x + y;

    println!("x: {}", x);
    println!("y: {}", y);
    print_type_of("result", &result);
}
```

Тем не менее Rust способен вывести необходимые типы.

Это называется **type inference — вывод типов**.

Позже мы будем часто пользоваться этой возможностью.

## 2.24. Контекст может определять тип

Сравним:

```rust
let x = 42;
```

и:

```rust
let x: u8 = 42;
```

Но существует ещё один интересный вариант:

```rust
fn main() {
    let x: u8 = 42;
    let y = x + 1;

    println!("{}", y);
}
```


## 2.26. Выражение имеет результат

Вернёмся к нашей основной идее:

```rust
2 + 2
```

Это выражение.

У него есть результат:

```text
2 + 2
  ↓
  4
```

Причём результат также имеет тип.

Например:

```text
2 + 2
  ↓
  4
  ↓
 i32
```

А:

```text
2.0 + 2.0
```

даёт:

```text
2.0 + 2.0
     ↓
    4.0
     ↓
    f64
```

Проверим:

```rust
fn main() {
    let a = 2 + 2;
    let b = 2.0 + 2.0;

    println!("{}", a);
    println!("{}", b);
}
```

# 2.34. Что мы узнали

В этой главе мы сделали первый серьёзный шаг от простого запуска программ к пониманию модели Rust.

Мы узнали, что:

- программа работает со **значениями**;
- каждое значение имеет **тип**;
- Rust имеет различные целочисленные типы;
- для дробных чисел используются `f32` и `f64`;
- числа можно записывать в разных системах счисления;
- Rust умеет выводить типы;
- тип можно указывать явно;
- существуют числовые литералы с указанием типа;
- арифметические операции образуют **выражения**;
- выражение имеет результат;
- результат выражения также имеет тип;
- порядок арифметических операций определяется приоритетом операторов;
- скобки позволяют изменить этот порядок;
- целочисленное деление отличается от floating-point division;
- `%` вычисляет остаток;
- floating-point arithmetic имеет ограниченную точность;
- Rust не выполняет произвольные неявные преобразования числовых типов;
- ошибки типов обнаруживаются компилятором;
- ошибки можно специально исследовать в Rust Playground.

Главная схема главы:

```text
┌───────────┐
│ Значение  │
└─────┬─────┘
      │
      ▼
┌───────────┐
│   Тип     │
└─────┬─────┘
      │
      ▼
┌───────────┐
│ Операция  │
└─────┬─────┘
      │
      ▼
┌───────────┐
│ Выражение │
└─────┬─────┘
      │
      ▼

      │

```

Именно понятие **выражения** станет особенно важным в следующих главах.

---

# 2.35. Что дальше?

До сих пор мы в основном использовали значения непосредственно:

```rust
2 + 2
```

Но в реальной программе результаты вычислений нужно **сохранять**, чтобы использовать их позже.

Например:

```text
2 + 2
  ↓
  4
  ↓
сохранить
  ↓
использовать позже
```

Для этого Rust предоставляет механизм, с которым мы уже немного познакомились:

```rust
let
```

В следующей главе мы подробно разберём:

> **переменные, binding и `let`.**

И увидим, как значение, полученное выражением, превращается из временного результата вычисления в часть состояния нашей программы.
