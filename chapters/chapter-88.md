# Глава 88. Как следить за развитием Rust

Rust — это живой язык. Он постоянно развивается: появляются новые функции, улучшаются инструменты, растёт экосистема. Чтобы оставаться в курсе и эффективно использовать Rust, важно знать, где искать информацию о его развитии.

В этой главе мы составим карту ресурсов, которые помогут вам следить за изменениями в языке, инструментах и экосистеме Rust.

---

## 88.3. Процесс разработки

## RFC (Request for Comments)

**Предложения по изменению языка или экосистемы.**

```
github.com/rust-lang/rfcs

```

**Что это:**

* Формальный процесс для больших изменений.
* Обсуждение дизайна до реализации.
* Принятие или отклонение.

**Статусы RFC:**

* `Active` — открыт для обсуждения.
* `Accepted` — принят, можно реализовывать.
* `Implemented` — реализован в nightly.
* `Stabilized` — доступен в stable.

## Tracking Issues

**Отслеживание прогресса конкретных функций.**

```
github.com/rust-lang/rust/issues?q=label%3AT-tracking

```

**Что это:**

* Отслеживание реализации.
* Обсуждение деталей.
* Блокирующие проблемы.

**Как найти:** ищите label `T-tracking`.

## Release Notes

**Что нового в каждой версии.**

```
doc.rust-lang.org/nightly/release-notes.html

```

**Что содержит:**

* Новые стабилизированные функции.
* Исправленные баги.
* Улучшения производительности.
* Обновления инструментов.

## 88.6. Инструменты для отслеживания

## rustup

**Управление версиями Rust.**

```bash
# Показать доступные версии
rustup show

# Обновить до последней stable
rustup update stable

# Проверить установленные компоненты
rustup component list

```

## cargo outdated

**Проверка устаревших зависимостей.** Утилита позволяет увидеть, какие внешние крейты в вашем проекте имеют более свежие версии на crates.io, помогая поддерживать стек в актуальном состоянии.

```bash
cargo install cargo-outdated

cargo outdated

```

## cargo audit

**Проверка уязвимостей в зависимостях.** Сканирует граф зависимостей проекта по базе известных уязвимостей (Rust Securty Advisory Database).

```bash
cargo install cargo-audit

cargo audit

```

### cargo tree

**Визуализация дерева зависимостей.** Позволяет понять, почему конкретный крейт попал в сборку и какие версии транзитивных зависимостей используются.

```bash
# Вывести полное дерево зависимостей проекта
cargo tree

# Ограничить глубину вывода до 2 уровней
cargo tree --depth 2

```

Хорошие новости и ресурсы помогают оставаться в курсе, понимать направление развития языка и использовать его возможности с максимальной эффективностью. Регулярное чтение `This Week in Rust` и просмотр `release notes` даст вам 90% нужной информации без перегрузки. Остальное — по мере необходимости.
